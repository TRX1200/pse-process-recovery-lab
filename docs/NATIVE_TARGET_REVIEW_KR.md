# 목표 단면과 공정 평가 사용법

이 기능은 사용자가 정한 목표와 ViennaPS 계산 형상을 비교합니다. 판정 버전은 `native-target-review-1.0`입니다. 기본 목표는 학습용 예시이며 산업 합격 규격, 최적 레시피, 실측으로 교정된 기준이 아닙니다.

## 바로 실험하기

1. Etch 또는 ALD를 선택하고 시편을 고릅니다. 저장된 예제로 먼저 연습해도 됩니다.
2. **목표 설정**에서 깊이·폭 또는 두께, 허용오차, Rq 상한을 입력합니다. 목표는 현재 화면에 표시된 시편에 적용됩니다. 새 시편 종류를 계산한 후에는 목표 항목도 그 종류에 맞게 바뀝니다.
3. 붉은 주황색 목표선과 현재 단면을 확인합니다. 목표선만 바꾸는 것은 재계산이 아닙니다. 공정 조건을 바꾼 후 **Run simulation**을 실행합니다.
4. 재생 버튼과 프레임 슬라이더로 실제 저장 프레임을 살펴봅니다. 화면은 0.65초마다 한 프레임을 보여주며 실제 공정 시간과 다릅니다.
5. **최종 평가**에서 미달 항목과 다음 비교 조건을 읽습니다. 하나의 지표로 원인을 확정하지 말고 한 변수씩 바꿔 비교합니다.
6. **보고서에 담기**를 눌러 최종 지표·당시 목표·판정을 함께 고정합니다. **현재 평가 JSON**은 지금 선택한 프레임의 평가를 저장합니다. 목표를 바꾸어도 이미 담은 기록은 변하지 않습니다.

목표는 현재 브라우저 탭에 임시 저장되어 메뉴 이동·새로고침 후에도 유지됩니다. 탭을 닫기 전에는 보고서나 평가 JSON에도 보관하세요. 목표가 다른 두 기록은 동일 기준의 비교로 처리하지 않습니다. 중간 프레임은 최종 평가와 구분하며, 계산 중에는 목표 변경과 결과 내보내기를 잠급니다.

## 초기 형상 세 가지의 뜻

| 시편 | 확인하려는 질문 | 주의 |
|---|---|---|
| 패턴 / 평활 트렌치 | Etch 깊이·폭·바닥, ALD 상단·바닥 피복과 통로 | Etch는 마스크가 있는 초기 기판, ALD는 이미 파인 홈 |
| 평면 요철 | 초기 ripple의 높이와 거칠기가 얼마나 달라지는가 | 전체 폭에 초기 주기 형상을 직접 지정 |
| 요철 측벽 | 초기 scallop을 식각하거나 덮으면 벽과 막이 어떻게 변하는가 | Bosch 생성 공정을 계산하는 옵션이 아님 |

이들은 공정의 1·2·3단계가 아니라 독립적인 시험 시편입니다. 동일 초기 형상끼리 조건 변화의 효과를 비교하세요.

## 목표 형상과 판정

- **Etch 트렌치**: y = 0부터 목표 최종 깊이까지 파인 직사각형. 목표 폭은 절반 깊이의 계산 CD와 비교합니다. 요철 측벽 시편의 목표 깊이는 초기 깊이를 포함한 총 깊이입니다.
- **Etch 평면**: 초기 평균면 기준 목표 제거량. 붉은 주황선은 그 제거량의 평탄한 최종 면입니다.
- **ALD**: 초기 Si 경계를 목표 두께만큼 기체 방향의 법선으로 이동한 설계 안내선. 꼭짓점은 인접 법선으로 연결하고 이동량을 목표 두께의 2배 이내로 제한합니다. 모서리·자기 교차를 일반적으로 해결하는 성장 해석기가 아닙니다. 트렌치 목표 두께가 초기 폭의 절반 이상이면 목표선과 평가를 보류합니다.
- **ALD 평면**: 요철을 따라 덮는 목표 또는 평탄한 최종 면 중 선택합니다. 두께 항목은 평균 높이 증가이므로 요철면의 국소 법선 두께와 같지 않을 수 있습니다.

각 조건을 충족하면 `목표 충족`, 하나라도 미달이면 전체 `목표 미달`입니다. 미달은 없지만 측정할 수 없는 항목이 있으면 전체 `평가 불가`입니다. 종합 점수나 가중치는 만들지 않습니다. ALD 막이 아직 0일 때 바닥/상단 두께비는 정의할 수 없으므로 정상이나 0%로 판정하지 않습니다.

목표 변경은 결과를 재평가할 뿐 원시 JSON·표면·물리 파라미터를 수정하지 않습니다. 결과에 맞춰 목표를 변경했다면 보고서에 사후 변경이라고 기록하세요.

## 측정 정의와 그래프

모든 길이는 nm입니다. y는 위쪽 양수, 깊이는 y = 0 아래의 양수입니다.

| 항목 | 정의 / 측정 범위 |
|---|---|
| 평면 Rq | 전체 폭의 256개 중점에서 위쪽 표면을 샘플링. `sqrt(mean((h-mean(h))²))` |
| 바닥 Rq | 초기 개구 폭 중앙 60%의 65개 중점. 평균면만 제거하며 기울기는 남김. 모서리의 microtrench 전체를 대표하지 않음 |
| 측벽 Rq | 깊이 10–90%의 161개 위치에서 좌우 벽을 측정하고 각각 최적 직선을 제거. 요철 측벽·ALD는 고정 초기 깊이, 패턴 Etch는 해당 시점의 깊이. 평가에는 좌우 중 큰 값 |
| 목표 단면 RMS 거리 | 양방향 각각 호 길이 등간격 97표본의 최근접 선분 거리 d를 모아 `sqrt(mean(d²))`. 최악의 국소 결함 크기나 Hausdorff 거리가 아님 |
| Etch 목표 비교 표면 | Si level set에 포함된 마스크 union의 y > 0 부분을 원래 보호 기판면 y = 0으로 투영. 마스크 높이를 Si 식각 오차로 오인하지 않음. 표시 단면 자체는 원시 층 경계를 유지 |
| 구간 평균 진행률 | 완료 구간의 진행량 차이 / 실제 시간 또는 사이클 차이. 첫 프레임에는 정의하지 않음 |
| ALD 바닥 / 상단 | 원시 엔진 지표의 두께비. 상단 두께가 0이면 평가 불가 |
| ALD 최소 통로 | 엔진의 샘플 위치 최솟값. 연속 형상의 전역 최솟값을 보장하지 않음 |
| ALD 깊이별 막 거리 | 현재 코팅 벽 표본에서 초기 Si 선분까지의 최단 거리. 국소 법선 두께와 다를 수 있음 |

평면 요철은 6개, 트렌치 Etch·ALD는 각각 8개 그래프를 제공합니다. 시간/사이클 이력과 현재 시점의 공간 분포를 구분합니다. 요철 확대 그래프는 평균 높이를 제거한 실제 nm 값이며 시각 효과용 잡음을 더하지 않습니다.

목표 허용오차·Rq 상한이 grid보다 작으면 수치 민감도 경고를 표시합니다. 경고가 없더라도 정확도가 보장되지는 않습니다. grid, seed, rays를 바꾼 수렴·민감도 확인 및 실측 비교가 필요합니다.

## 입자 애니메이션의 의미

Etch에서는 이온·F·O 공급, thermal ALD에서는 TMA 공급과 흡착을 설명하는 기호를 보여줍니다. 해당 입력 공급이 0이면 그 입자 종류를 표시하지 않습니다. 입자 수, 직선 이동, 표면의 점멸과 공급 영역의 발광은 정량 궤적이나 피복률 데이터가 아닙니다. 입자들은 보여 주기 위한 표면 교점으로 이동하며 실제 반사·산란 궤적을 재생하지 않습니다.

**표면만 실제 해석기의 저장 프레임**입니다. 입자 표시를 꺼도 계산과 판정은 같습니다. ALD에 플라즈마를 그려 넣지 않습니다. 별도 RF–Ar 해석을 화학 식각이나 thermal ALD에 자동 결합하지 않습니다. SVG 내보내기에서는 설명용 입자·발광을 제외하고 목표·시점·평가 기준을 metadata에 기록합니다.

## 보고서의 작은 실험 예시

Etch는 목표 깊이를 고정하고 이온 방향성만 바꿔 폭·벽 Rq·바닥 Rq·목표 형상 거리의 변화를 비교합니다. ALD는 같은 트렌치·목표 두께·사이클 수에서 노출 시간만 바꿔 상단 두께, 바닥 피복, 통로를 함께 봅니다. 평면 요철에서는 초기 Rq 대비 변화가 격자·표본 오차보다 큰지 확인한 다음 평탄화 여부를 논의하세요. 이 예시의 개선 결과는 미리 보장되지 않습니다.
