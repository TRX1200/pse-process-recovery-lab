# 실험 노트 화면 개편과 검증

## 목적

첫 방문자가 연구 질문과 비교 조건을 이해하고, 계산 근거·원시 데이터·직접 작성한 해석까지 따라갈 수 있도록 개편했습니다. 수치 모델과 기존 레시피 JSON 형식은 변경하지 않았습니다.

## 화면 설계 기준과 대조

작업 중 생성한 1536 × 1024 화면 시안을 구현 기준으로 사용하고, 같은 크기의 브라우저 캡처를 시안과 함께 이미지로 열어 대조했습니다. 사용자에게 디자인 승인을 받았다는 의미는 아닙니다.

| 항목 | 시안 기준 | 구현 확인 및 의도적인 차이 |
| --- | --- | --- |
| 목적·문구 | 식각 깊이 변화라는 연구 질문, 세 조건 비교 | 첫 화면에 질문과 모델 연결 경로를 배치. 모호한 마케팅 문구 제거 |
| 구조 | 상단 텍스트 메뉴, 왼쪽 실험 설계, 오른쪽 표·곡선 | 장식용 아이콘 레일을 제거. 반응기 개념도는 개별 레시피 화면에서 펼쳐 보기 |
| 글자 | 명확한 제목, 짧은 설명, 읽을 수 있는 표 | 기존 전역 테이블의 10px 글꼴 상속을 수정. 표 13–14px, 수식은 별도 수학 글꼴 |
| 색·구획 | 흰 배경, 짙은 글자, 얇은 선, 붉은 갈색 강조 | 카드 격자·배경 그라데이션 없이 구현. 시안 버튼의 미세한 명암은 단색으로 처리 |
| 데이터 | 계산 전 빈 표·빈 그래프 | 임의 수치를 넣지 않음. 실제 계산 후 세 조건의 원시 응답을 표시 |
| 필수 추가 요소 | 시안에 없는 실제 실험 조작 | 이상 강도·조치 입력, 규격 판정, 실행 ID를 추가. 가설·해석을 분리해 세로 길이가 늘어남 |
| 수식 | 서술과 계산 근거를 읽을 수 있는 조판 | Etch 17개, ALD 14개 식을 KaTeX + MathML로 렌더링. 폰트를 배포 파일에 포함 |
| 작은 화면 | 자연스러운 세로 배치 | 390 × 844에서 화면 자체의 가로 넘침 없음. 긴 비교표만 내부 가로 스크롤. 1280 × 720에서 실행 버튼이 첫 화면 안에 위치 |

시안의 물리 설명 중 실제 RF 회로 해석으로 오해할 수 있는 문장은 현재 구현 범위에 맞게 수정했습니다. 빈 그래프에 임의의 축 범위를 넣지 않습니다. 장비 검증이나 학습 성과를 보여 주는 가짜 배지·점수는 없습니다.

## 실행한 검증

- Python: `python -m unittest discover -s sim_app/tests -v` — 41개 통과.
- 프런트엔드: `pnpm test` — 29개 통과. 수식 조판, 비교 조건 분리, 서로 다른 사이클 길이와 보간 범위를 포함합니다.
- 배포 빌드: `pnpm build:pages` — 통과. Vite의 500 kB 청크 권고 경고가 있으며 빌드는 성공합니다.
- 배포 의존성: 처음 선택한 KaTeX 0.18.10은 발행 후 24시간이 지나지 않아 CI의 최소 발행 기간 정책에 차단됐습니다. 정책을 유지하고, 2026-09-23 발행된 0.18.9로 고정한 뒤 수식·전체 프런트엔드 테스트와 빌드를 다시 통과했습니다.
- 브라우저: Etch 3조건, ALD 3조건, 입력 변경 시 이전 결과 표시, 개별 실행 열기, 시간 재생·개념도 펼치기, Etch 3지점 스윕, 실행 기록을 점검했습니다.
- 파일 내보내기: 실제 다운로드한 ALD JSON·Markdown에서 전체 입력, 실행 ID, 모델 버전, 직접 입력한 검증용 메모를 확인했습니다. 검증용 메모는 화면에서 지웠습니다.
- 브라우저 Python 대 로컬 Python: ALD 세 조건의 결과·기준 데이터 수치 20,625개를 비교해 상대 허용 오차 1e-7, 절대 허용 오차 1e-9 안에서 일치했습니다. 최대 절대 차이는 약 3.143e-10입니다.
- 실제 렌더링: 데스크톱과 390px 화면의 ALD/Etch 수식을 캡처해 확인했습니다. KaTeX 오류 요소는 0개였고 수학 폰트가 로드됐습니다.

이 검증은 구현·표시·재현성 확인입니다. 실제 장비 데이터와의 일치, 고장 진단 정확도, 실제 공정 품질을 검증한 결과가 아닙니다. 공정별 직접 작성한 해석은 아직 사용자가 채워야 할 학습 기록입니다.
