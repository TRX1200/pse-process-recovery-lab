# AMK PSE: Etch + Deposition 프로젝트 명세

이 문서는 구현 계획과 학습 명세입니다. 실제 구현·실행·검증 상태는 README와 실행 기록을 확인하세요.

## W01 Etch와 Deposition, 두 사례를 끝까지

AMK PSE 지원을 위해 반도체 공정에 대한 관심과 문제 해결 능력을 보여주는 중소 규모 프로젝트다. 이름은 PSE Process Recovery Lab: Etch + Deposition이다. 두 공정의 물리와 측정 결과를 연결하고, 어떤 가설을 왜 확인하며 언제 조치를 보류하는지 자신의 언어로 설명한다.

| 사례 | 핵심 질문 | 완료 산출물 |
| --- | --- | --- |
| Etch | 식각 속도가 떨어졌을 때 무엇부터 확인할까 | 가설 비교·작은 DOE·회복 검증 |
| Deposition / PVD | 두께는 비슷한데 막 저항이 왜 바뀌었을까 | 두께/물성/계측 분리·조건 비교·판단 |

증착 주력은 RF·플라즈마·진공과 연결되는 PVD다. ALD/CVD는 마지막의 전이 질문으로 이해를 넓힌다. 두 사례는 공통 분석 도구를 쓰되 서로 다른 시험이며, 하나의 검증된 연속 제조 공정이라고 가정하지 않는다.

**규모의 상한**
저장소 1개, 사례 2개, 사례별 최종 그림 3장과 보고서 1쪽. 핵심은 비교 실험과 설명이다. 자동 진단 AI·실시간 제어·대형 대시보드는 이번 완료 조건에 포함하지 않는다.

공개 PSE 공고의 가설 실험·DOE·통계 분석·원인 분석·고객 소통을 연습하는 개인 프로젝트다. 실제 장비 모델이나 회사 공식 교육자료는 아니며, 공개 공고의 지원 자격은 별도로 확인한다.

## W02 두 고객 이슈와 보여줄 문제 해결 능력

| 교육용 상황 | 바로 내리면 안 되는 결론 | 직접 남길 증거 |
| --- | --- | --- |
| Etch: rate 감소·RF 반사 비율 증가 | RF matching 고장으로 확정 | 측정/가스/압력과 구분할 평가 |
| Etch: 압력 표시만 이동 | Recipe 압력을 즉시 보정 | Reference와 독립 KPI 비교 |
| PVD: 두께 유사·sheet resistance 증가 | 증착 시간 증가로 해결 | 두께·비저항·측정 접촉 분리 |
| PVD: 두께 계측기 간 차이 | 실제 성장량이 변했다고 확정 | 동일 wafer/site 재측정 |

첫날 제공 데이터는 각 사례의 관측을 비교하는 입문용이다. 후속 프로젝트에서는 한 주요 이상 사례를 골라 고정 조건과 바꿀 조건을 정하고, 제한된 평가로 가설을 좁힌다. 관측만으로 원인이 구분되지 않으면 필요한 추가 증거를 제시하는 것도 결과다.

**관심을 드러내는 지점**
Etch에서는 radical·ion·표면 반응과 여러 KPI를 연결한다. PVD에서는 입자 수송·성장·미세구조와 막 특성을 연결한다. 그래프를 그린 이유, 예상과 다른 결과, 다음 실험을 선택한 이유가 프로젝트의 중심이다.

**코드를 많이 만들어야 설득력이 생길까?**
작은 코드라도 단위와 가정, 대조군, 반증 기준, 독립 검증이 분명하면 자신의 판단을 설명하기 쉽다. 실제로 구현하고 이해한 범위까지만 본인의 기여로 적는다.

## W05 문제 정의와 가상 요구조건을 먼저 고정

문제 문장은 대상 공정·변화 시점·범위·지표·기준을 포함한다. “공정이 나쁘다” 대신 같은 정의와 측정법으로 baseline과 이상군의 평균·분포·위치별 차이를 비교한다. CASE라는 이름만으로 원인을 판정하지 않는다.

| 공정 | 교육용 요구조건 | 정의 |
| --- | --- | --- |
| Etch | Rate 95~105 nm/min | 동일 제거량/시간 정의 |
| Etch | CD bias -2~+2 nm | After-etch minus before-etch |
| Etch | Selectivity ≥8, NU ≤3% | 목표막/기준막, range 기반 NU |
| PVD | Thickness 19~21 nm | 같은 film model·site 조건 |
| PVD | Sheet resistance 9~11 ohm/square | 같은 측정 조건의 막 저항 |
| PVD | Thickness NU ≤3% | 9-site 예제, 측정 정의 고정 |

**수치의 출처**
위 수치는 과제 평가용으로 정한 가상 spec이다. 실제 고객 spec·특정 재료의 표준값·장비 운전 범위가 아니다. Test를 본 뒤 합격하도록 넓히지 않는다.

**평균만 spec 안이면 끝인가?**
각 wafer와 위치별 이탈, 반복성, 다른 KPI를 확인한다. 초기 프로젝트에서는 spec 이탈 수와 범위를 모두 보고하고, 최종 합격 기준을 평가 전에 정한다.

## W06 측정이 공정 변화를 제대로 나타내는가

`NU_range = 100 (max - min) / (2 mean)`

이 문서에서 쓰는 불균일도 [%]. 다른 NU 정의와 혼용하지 않는다. Site 수·좌표·edge exclusion을 고정하고 평균이 0 이하이면 계산을 거부한다.

| 확인 | Etch에서 | PVD에서 |
| --- | --- | --- |
| Quantity | 평균 rate인지 step rate인지 | 두께인지 sheet resistance인지 |
| 같은 위치 | Pre/post 대응 site | 두께와 저항의 대응 site |
| 반복성 | 같은 wafer 재측정 | Probe/두께 모델 재측정 |
| 독립성 | Gauge와 공정 KPI 분리 | 두께 reference와 막 저항 비교 |
| Sampling | Wafer 평균과 map 구분 | 9 site는 해당 wafer의 관측 |

첫날 Etch 데이터는 wafer 요약값이며 실제 site map을 포함하지 않는다. 제공된 NU 값을 raw site에서 재계산했다고 주장하지 않는다. PVD에는 site 데이터가 있으므로 NU를 직접 재계산하여 요약 CSV와 맞출 수 있다.

**최소 평가**
기준군과 이상군의 수·단위·결측을 확인한다. 같은 wafer를 반복 측정하는 시험과 새 wafer를 처리하는 시험을 구분한다. 평균을 많이 내도 공통 calibration bias는 사라지지 않는다.

## W07 데이터 계약과 평가 구간

| 항목 | 저장할 것 | 판단 기준 |
| --- | --- | --- |
| 식별 | case_id, wafer_id, site_id | 같은 실험·위치를 대응 |
| 단위 | nm, nm/min, W, mTorr, ohm/square | RF ratio는 fraction으로 저장 |
| 설정 | seed, model version, recipe condition | 입력과 출력·가정을 분리 |
| 순서 | wafer_index, run_id | 순서와 독립 평가 단위를 구분 |
| 정답 | instructor_only의 latent state | 분석기 입력으로 쓰지 않음 |

첫날 데이터에는 실제 timestamp가 없고 wafer_index만 있다. 실시간 진단이나 실제 생산 이력의 재현이라고 표현하지 않는다. 후속 실험은 설정과 seed, 생성 시점·평가 시점을 기록하고 test 전에 선택한 조건을 고정한다.

**분리 규칙**
개발: 가설·그림·분석 코드를 만든다. Validation: threshold·모델·조건을 고른다. Test: 고정한 설계를 새 seed/wafer로 확인한다. 같은 wafer의 site를 행 단위로 나누어 train/test에 넣지 않는다.

**새 seed면 현실에서도 검증된 것인가?**
같은 합성 모델 안의 반복 검증이다. Model family와 계수·noise 가정의 영향은 별도 한계로 남으며, 실제 장비로 일반화하려면 독립 실측이 필요하다.

## W09 식각의 변수와 결과를 연결한다

| 변수/상태 | 생각할 경로 | 확인 결과 |
| --- | --- | --- |
| Source와 bias | 생성·해리·sheath의 주된 역할 | Rate·CD·selectivity |
| Pressure와 gas | 충돌·반응종·부산물 수송 | Profile·NU·rate |
| Wall와 seasoning | 반응종 소모·표면 이력 | Wafer 순서와 drift |
| 측정·입력막 | 두께·시간·교정의 차이 | 독립 제거량·reference |

`P_net,plane = P_forward - P_reflected`

같은 교정 기준면에서의 전력 수지 [W]. 하류 손실과 비선형 plasma 때문에 이 값이 곧 흡수 전력이라고 단정할 수 없다.

**기존 RF 경험을 어떻게 연결할까?**
반사 비율 자체보다 기준면·교정·부하 변화와 측정 불확실성을 설명한다. Plasma chemistry와 실제 장비 경험은 별도의 학습·검증 범위다.

## W10 속도 저하와 압력 표시 이동을 구분

먼저 baseline과 CASE_A/B의 rate, CD, selectivity, NU, RF ratio, pressure reference를 비교한다. 변화량과 관측 구간을 적은 뒤 설명 후보를 만든다. 실제 원인 label을 보기 전에 표의 빈칸을 자신의 데이터 값으로 채운다.

| 가설 | 예상하는 관측 | 가설을 약화시키는 결과 |
| --- | --- | --- |
| 전달 상태 변화 | RF 지표와 독립 KPI 동반 변화 | 전달 확인 정상·계측 편향 확인 |
| 압력 제어 문제 | 독립 gauge·과도 응답도 변화 | Reference와 공정 KPI 정상 |
| 입력막/계측 차이 | 동일 조건 재측정에서 차이 | 다른 계측에서도 제거량 저하 |
| Monitor bias | 표시와 reference 불일치 | 독립 공정 상태도 함께 변화 |

**다음 평가의 예**
가스와 압력을 고정한 전달 상태 확인 / 같은 wafer의 독립 제거량 재측정 / 기준 gauge와 step 응답 비교 중 하나를 고른다. 어떤 두 가설을 구분하는지 먼저 적는다.

CASE_B는 모니터 전용 bias를 다루는 입문 예시다. Feedback 센서 bias라면 제어기의 동작을 바꿔 실제 공정도 변할 수 있다. 둘을 같은 고장으로 일반화하지 않는다.

**RF ratio 상승을 보고 원인 확정이라고 쓸까?**
Load와 wall·gas 변화의 결과일 수도 있다. 관측은 확정하되 원인은 유력/미해결로 구분하고 추가 평가 결과에 따라 수정한다.

## W11 작은 DOE로 공정창을 탐색한다

장비·센서 이상을 먼저 확인한 뒤 조정 가능한 상태에서 조건을 비교한다. 예시 factor는 정규화한 source와 bias다. 고정할 항목은 pressure, gas, time, 입력막, chamber state, metrology 조건이다.

| 실험 | 개수 | 고정할 규칙 |
| --- | --- | --- |
| 2×2 corner 조건 × 2회 반복 | 8 | 독립 noise·실행 순서 무작위화 |
| Center point | 4 | 반복 산포·곡률 단서 확인 |
| 선택 조건의 새 wafer | 10 | 설정 고정 후 독립 확인 |

Low/high는 기준값의 ±10%라는 교육용 정규화 범위로 시작한다. 실제 장비의 안전 범위라는 뜻은 아니다. Rate 하나를 최대화하지 말고 CD·selectivity·NU의 제약을 함께 확인한다.

**남길 그림**
조건별 KPI 표와 오차막대 / source×bias 효과 또는 response map / 선택 조건의 독립 확인 결과. 관측하지 않은 영역을 매끈한 surface로 그렸다면 모델 예측임을 표시한다.

**12회 실험에서 좋은 조건이 없으면?**
그 범위에서는 feasible 조건을 찾지 못했다고 보고한다. 하드웨어 이상, 범위, 모델 가정 또는 다른 공정 변수의 필요성을 다시 검토한다.

## W12 조치와 회복 검증을 분리해 기록

| 선택 | 적용할 근거 | 다음 확인 |
| --- | --- | --- |
| 재측정 | 계측 불일치 | Reference·동일 site 반복 |
| 장비 상태 복구 평가 | 전달/제어 이상 근거 | 고정 recipe의 여러 KPI |
| Chamber 상태 평가 | 이력과 drift·대조 evidence | Seasoning 이후 반복성 |
| Recipe 조건 선택 | 조정 가능한 공정창 확보 | 새 wafer의 spec·부작용 |
| HOLD | 원인 비식별·평가 데이터 부족 | 필요한 측정과 지원 요청 |

교육용 복구 함수가 latent loss를 0으로 돌리면 합성 모델 안의 개입이다. 실제 matching 부품 교체나 장비 복구를 수행한 경험이라고 쓰지 않는다. 실제 장비 조작 방법 대신 필요한 진단 근거와 역할을 설명한다.

**최소 확인**
선택한 설정을 고정하고 2개 가상 lot × 5 wafer에서 rate·CD·selectivity·NU를 모두 보고한다. 초기 기준은 모든 평가 wafer의 제약 충족으로 두되 이탈도 그대로 남긴다. 표본 10개는 양산 qualification의 충분한 수량을 뜻하지 않는다.

**“회복됨”을 언제 쓸까?**
어떤 합성 조건과 범위에서 사전 기준을 충족했는지와 함께 쓴다. 원인 확정, KPI 회복, 장기 안정성 검증은 각각 별도의 상태다.

## W13 PVD: 두께와 막 특성을 함께 본다

PVD sputtering에서는 target에서 방출된 종이 수송되어 표면에서 막을 형성한다. 압력에 따른 충돌, 입자의 에너지·입사각, 표면 이동성, 전처리와 오염은 막의 성장과 특성에 영향을 줄 수 있다.

| 변수/상태 | 생각할 물리 경로 | 확인할 것 |
| --- | --- | --- |
| Target power | 입자 공급·가열·plasma 변화 | Rate·두께·막 특성 |
| Pressure | 충돌·수송 각도·에너지 | 두께 map·coverage·저항 |
| 기판 온도/표면 | 핵생성·이동·계면 | 조성·구조·접촉·stress |
| Target/chamber 이력 | 방출 분포·누적 상태 | Repeatability·particle·map |

이번 주력 지표는 두께, sheet resistance, 두께 NU다. Stress·coverage·particle도 중요한 현실 지표지만 제공 데이터에는 없으므로 측정 계획과 미검증 범위로 남긴다. 모든 막 품질을 검증했다고 표현하지 않는다.

**PVD를 선택한 이유**
기존 RF·진공 이해를 막 형성의 수송·표면 반응·물성 문제로 넓힐 수 있다. 지원 부서가 CVD/ALD이면 공고에 맞춰 증착 사례의 메커니즘과 KPI를 바꾸되, 가설·평가·검증의 공통 구조는 유지한다.

## W14 두께가 같은데 저항이 커진 이유

`R_sheet = rho / t ; rho_apparent = R_sheet × t`

단일 균일 도전막의 근사. R_sheet [ohm/square], rho [ohm·m], t [m]. 두께 nm를 m로 바꿀 때 10^-9를 곱한다. 다층 전도·불연속 막·초박막 효과는 추가 모델이 필요하다.

**손계산 예제**
t=20 nm, R_sheet=10 ohm/square이면 rho_apparent=2×10^-7 ohm·m. 같은 두께에서 12.5 ohm/square이면 2.5×10^-7 ohm·m다. 이는 교육용 가정값이며 특정 재료의 표준 물성값이 아니다.

R_sheet가 증가했다고 곧바로 오염이라고 단정할 수 없다. 실제 두께, 조성·미세구조, 계면, probe 상태와 계측 모델을 확인한다. 두께와 저항이 다른 site에서 측정됐다면 먼저 위치를 맞춘다.

**증착 시간을 늘려 저항을 맞추면 되나?**
rho=2.5×10^-7 ohm·m에서 10 ohm/square를 만들려면 두께 25 nm가 필요하다. 가상 두께 spec 19~21 nm를 벗어난다. 저항 하나의 보상은 전체 공정 회복을 뜻하지 않는다.

이 계산은 경쟁 가설을 정리하는 도구다. 사용한 두께 측정에 bias가 있으면 rho_apparent도 같이 치우치므로 독립 reference와 측정 반복이 필요하다.

## W15 두께·물성·계측의 세 가설을 분리

| 가설 | 예상 관측 | 구분할 평가 |
| --- | --- | --- |
| 실제 두께 감소 | 독립 두께도 감소·저항 증가 | 대응 site 두께와 제거/성장량 |
| 막 특성 변화 | 독립 두께 유사·저항 이동 | 재측정·조성/구조/이력 확인 |
| 두께 계측 bias | Monitor와 reference 불일치 | 동일 wafer의 모델·기준 비교 |
| 저항 계측 문제 | Probe/측정 조건별 값 변화 | Reference sample·반복 측정 |

PVD starter의 CASE_A는 숨은 비저항 변화만 주입한다. 그 비저항 변화가 오염·결정립·온도 중 무엇 때문인지는 모델이 정의하지 않는다. Label을 보아도 실제 물리 원인이 확정되는 것은 아니다.

**실제 작성할 문장**
“동일 site의 reference 두께와 저항을 비교하면 단순 두께 감소만으로 설명하기 어렵다. 막 특성과 저항 측정의 가설이 남는다. Probe 반복성과 기준 시편을 먼저 확인한 뒤 필요한 물성 분석을 요청한다.” 수치·판단은 자신의 실행 결과로 채운다.

**CASE_B의 monitor 두께가 늘었으면 성장량이 늘었나?**
Reference와 저항이 함께 지지하는지 본다. 모니터 전용 bias를 실제 성장 변화로 오해하면 불필요한 recipe 조정을 하게 된다.

## W16 PVD의 작은 DOE와 Trade-off

예시 factor는 정규화한 target power와 process pressure다. 고정할 항목은 deposition time, substrate condition, target/chamber state와 측정법이다. 먼저 장비·계측 상태가 비교 가능한지 확인한다.

| 구성 | 처리 | 보고 |
| --- | --- | --- |
| 2×2 corners × 2회 | 8개 독립 실현 | 두께·저항·NU 각각의 효과 |
| Center point × 4회 | 반복성과 곡률 확인 | 평균·산포·center 차이 |
| 새 wafer의 선택 조건 | 2개 가상 lot × 5 wafer | 동시 spec 충족·이탈 수 |

Target power를 올리면 모든 물성이 좋아진다고 가정하지 않는다. 교육 모델에서 정한 방향과 실제 재료에서 검증된 경향을 구분한다. DOE 결과가 약하거나 불확실하면 더 좁은 결론과 다음 평가를 남긴다.

**공정창 그림**
가로축 power, 세로축 pressure에 두께·R_sheet·NU 제약을 동시에 만족하는 영역을 표시한다. 서로 다른 단위의 KPI를 무작정 더하지 않는다. 계산 가능한 영역과 미측정 영역을 구분한다.

**모든 조건이 spec 밖이면 실패 프로젝트인가?**
적용 범위 안의 비실현 가능성과 그 이유를 보이면 유효한 결과다. Target이나 spec을 사후 변경해 성공처럼 만들지 않는다.

## W17 막 특성을 보상하는 것과 원인 해결

단순 두께 보정, material state 회복, 계측 보정은 서로 다른 조치다. 특히 두께를 늘려 R_sheet만 낮추면 CD budget·step coverage·다른 층의 요구와 충돌할 수 있다. 이번 데이터로 검증하지 않은 항목은 영향 확인이 필요하다고 표시한다.

| 조치 후보 | 어떤 증거가 필요한가 | 확인할 부작용 |
| --- | --- | --- |
| 시간/조건 조정 | 정상 물성·안정된 delivery | 두께·NU·다른 막 특성 |
| 계측 방법 점검 | 반복성/기준과 불일치 | 보정 전후 비교·추적성 |
| 표면/막 상태 확인 | 두께로 설명 안 되는 저항 | 조성·구조·계면 데이터 |
| HOLD와 추가 평가 | 비식별·가상 spec 동시 충족 불가 | 필요한 측정·고객 영향 |

**닫을 수 있는 결론**
“두께 변화 가설은 약해졌으나 막 물성의 세부 원인은 미확정”도 가능하다. 해결을 주장하려면 고정한 조치 뒤 새 wafer에서 두께·저항·NU의 사전 기준을 함께 확인한다.

첫날에는 실제 공정 조치·DOE가 실행되지 않는다. 후속 모델에 조치를 넣었다면 상태 변경 규칙을 공개하고, 임의의 완전 회복 함수를 실제 공정 복구의 증거로 바꾸지 않는다.

## W18 입문 데이터와 조건 변경 모델의 경계

Starter는 관측 해석을 위한 고정 시나리오 생성기다. 입력 recipe를 바꾸는 DOE용 solver가 아니다. 다음 식은 후속 구현에서 사용할 수 있는 작은 response model의 설계 예시이며 아직 물리적으로 검증한 관계가 아니다.

`Etch: R = 100 (1-r) (1+0.35a+0.15b+0.50ab)`

a=source/source0-1, b=bias/bias0-1, r은 latent loss. R [nm/min]. a,b는 [-0.1,+0.1]만 허용한다. CD=3a+4b [nm], S=10-4b, NU=1.5+0.4|b| [%]도 교육용 예시다.

`PVD: t = 20 (1+0.60u-0.25v+1.50uv)`

u=power/power0-1, v=pressure/pressure0-1. t [nm]. rho=2×10^-7(1+0.30v+0.10u²) [ohm·m], R_sheet=rho/(t×10^-9). u,v는 [-0.1,+0.1]. 모든 계수는 학습용 가정이다.

PVD NU는 9-site 두께 모델을 먼저 만든 뒤 계산한다. 공정 변동은 wafer 상태에, 계측 noise는 관측에 넣고 각각의 분포와 크기를 기록한다. 미정의 KPI를 임의의 상수로 두어 제약을 통과시키지 않는다.

**필수 한계**
이 모델은 가정한 변수 관계에서 실험·제약·검증 절차를 연습하게 한다. 식으로 만든 결과를 같은 식으로 맞췄다고 실제 식각 chemistry나 PVD 수송을 입증한 것은 아니다. 계수·noise 변화도 별도 확인한다.

## W19 효과 계산과 독립 반복의 의미

| A | B | 가상 response |
| --- | --- | --- |
| -1 | -1 | 80 |
| +1 | -1 | 92 |
| -1 | +1 | 84 |
| +1 | +1 | 104 |

`y = 90 + 8 A + 4 B + 2 A B`

A,B는 coded -1/+1. A effect=16, B effect=8, AB effect=4. 이 convention에서 회귀계수는 effect의 절반이다. 실제 정규화 변수 a=0.1A와 혼동하지 않는다.

위 네 점만으로는 잔차 자유도가 없다. 같은 조건에서 새 wafer/measurement를 생성하는 독립 반복이 오차 추정에 필요하다. Center point는 전체적인 곡률 단서를 주지만 개별 2차항을 모두 식별하지는 못한다.

**실행할 분석**
공정별로 조건 평균·산포를 표로 만든다. 각 KPI의 main effect와 interaction을 계산하고 단위를 붙인다. 실행 순서와 residual도 확인하여 시간 drift와 factor를 혼동하지 않는다.

**p-value 하나로 좋은 recipe를 정할까?**
효과 크기·불확실성·다른 KPI·새 wafer 확인을 함께 본다. 약한 interaction을 유의하게 만들려고 결과를 골라내지 않는다.

## W20 불확실성과 HOLD를 결과에 포함

| 상태 | 올바른 보고 | 다음 행동 |
| --- | --- | --- |
| 가설의 예측이 같음 | 현재 관측으로 구분 불가 | 다른 측정/대조 조건 |
| Spec 경계와 오차가 겹침 | 판정 불확실 | 반복·reference 확인 |
| 모든 제약을 만족하는 조건 없음 | 현재 범위 INFEASIBLE | 원인·범위·가정 재검토 |
| 측정 누락·이상 입력 | INVALID 또는 HOLD | 계산 중지·이유 기록 |

10개 확인 wafer의 성공은 제한된 합성 평가다. 한 개도 이탈하지 않았다고 실제 공정의 실패 확률을 0으로 쓰지 않는다. Confidence interval과 prediction interval을 구분하고, 작은 표본에서는 개별 값도 보여준다.

**MVP의 판단 방식**
확률처럼 보이는 confidence 숫자를 만들 필요는 없다. 지지 증거·반대 증거·아직 없는 관측을 표로 남기고, 다음 평가를 최대 3개 이내로 우선순위화한다. 명시한 평가 예산 안에서 해결 못 하면 HOLD로 마친다.

**평균은 좋아졌지만 산포가 커지면?**
Spec 이탈 위험과 재현성까지 다시 본다. 평균 개선을 전체 공정 개선으로 축약하지 않는다.

## W21 그림 여섯 장과 검증 항목

| 사례별 그림 | Etch | PVD |
| --- | --- | --- |
| 1. 현상과 비교군 | Rate/CD·RF·압력 추세 | 두께-R_sheet와 reference 차이 |
| 2. 원인 구분과 DOE | 후보별 평가·조건 효과 | 두께/물성/계측 가설·조건 효과 |
| 3. 고정 후 확인 | 여러 KPI와 spec·개별 wafer | 두께·저항·NU의 독립 결과 |

그림마다 단위·조건·sample 수·seed·실험 또는 예측 여부를 표시한다. 최종 확인 전 단계라면 3번 그림은 검증 계획으로 표시하고 존재하지 않는 before/after 성과를 만들지 않는다.

**좁고 의미 있는 테스트**
같은 seed의 재현성, 잘못된 단위·분모 0 처리, rho=R_sheet×t 단위 관계, NU 재계산, 정답 분리, wafer 단위 분할을 확인한다. DOE·조치 구현 후에는 범위 밖 입력 거부와 새 seed의 평가 경로를 확인한다.

관측 비교만 구현했는지, DOE를 실행했는지, 독립 기준을 충족했는지를 README에 각각 적는다. Test suite의 통과를 실제 공정 모델 정확도나 현장 운용 능력으로 바꾸지 않는다.

## W24 제출 전 확인과 Deposition 확장 질문

| 확인 질문 | 자신의 자료에서 찾을 근거 |
| --- | --- |
| Etch와 PVD를 왜 골랐나 | 기존 역량과 새로 공부한 공정 물리 |
| 데이터가 가설을 반박한 적이 있나 | 실제 결과와 판단 변경 기록 |
| 왜 그 실험을 먼저 했나 | 예측 차이·고정 조건·비용 |
| 다른 KPI도 만족하는가 | 동시 spec과 개별 이탈 |
| 독립 검증인가 | 고정 설정·새 seed/wafer |
| 모델이 틀리면 무엇이 남는가 | 절차의 유효 범위·물리 검증의 한계 |

**ALD/CVD로 옮겨 생각하기**
ALD에서 같은 cycle인데 두께가 줄면 precursor 전달·표면 반응·온도·계측 중 무엇을 구분할까? Pulse saturation과 독립 두께 평가를 설계해 본다. CVD에서는 반응 제한과 수송 제한에서 온도·유량의 효과가 어떻게 달라질지 설명한다.

이 확장 질문은 세 번째 구현 프로젝트가 아니라 학습 전이 연습이다. 우선 두 주력 사례의 관측·가설·실험·검증을 완결한다. 부족한 데이터 때문에 HOLD인 경우도 다음 증거를 정확히 제시하면 보고서에 포함한다.

**이번 프로젝트에서 무엇까지 주장할 수 있나?**
명시한 합성 환경에서 공정 원리를 공부하고 평가·검증 절차를 구현한 범위다. 실제 고객 수율 개선·장비 운용·회사 recipe 최적화를 수행했다고 주장하지 않는다.
