# ALD model: delivery → transport → surface reaction → film

이 모듈은 입력 레시피가 먼저 챔버 분압과 표면 반응을 변화시키고, 그 결과로 두께를 계산하는 **교육용 열 ALD 축약 시뮬레이터**다. 불량 KPI를 직접 지정하지 않는다. 실제 장비 또는 특정 재료의 공정창을 보정한 모델은 아니다.

구현: `sim_app/models/ald.py` · 버전 `ald-reactive-diffusion-1.0.1`

1.0.1은 지배방정식과 수치해를 유지하고 재생용 첫 사이클 성장 분포를 출력한다. 공간 프레임은 적분 결과의 4번째 표본마다 추출하며, 화면은 표본 사이를 선형 보간한다. N회 투영 두께를 시간 비율로 늘리는 방식이 아니다.

## 1. 무엇을 직접 계산하는가

- A 주입 → A 퍼지 → B 주입 → B 퍼지 한 사이클의 시간 응답.
- 챔버의 A/B 분압, 깊이 방향 기체 수송, 반응에 의한 기체 소모.
- A로 종결된 표면의 비율, B 반응으로 생성된 막의 두께.
- 공급·배기·온도 이상을 상류 상태에 적용한 뒤 발생하는 결과 차이.

`cycles`는 **초기 한 사이클 결과 × 반복 횟수**다. 매 사이클 재계산이나 성장에 따른 형상 갱신을 하지 않는다. 잔류 가스가 크거나 표면 초기화가 불완전하면 반복 투영도 부정확해진다. 이 경우 결과에 경고를 추가한다. 이 한계를 감춘 채 수백 회의 실제 ALD를 재현했다고 쓰면 안 된다.

## 2. 좌표, 입력 및 상태

넓은 두 평판 사이 간격을 H, 입구에서 막힌 끝까지 깊이를 L로 둔다. x=0은 입구, x=L은 막힌 끝이다. x만 공간적으로 해석하고 온도는 균일하다고 가정한다. 채널 단면적이나 챔버 체적을 주지 않으므로 총 유량(sccm)을 추정하지 않는다. 입력 압력은 **반응물 분압(Pa)**이며 총압이 아니다.

| 변수 | 의미 | 단위 |
| --- | --- | --- |
| P_A, P_B | 챔버 분압 | Pa |
| p_A(x), p_B(x) | 채널 내부 분압 | Pa |
| θ(x) | A 종결 표면 비율 | 0–1 |
| z(x) | 누적 B 전환 횟수 | 무차원 |
| q | 유효 표면 자리 밀도 | m⁻² |
| g_sat | 한 번 완전히 전환될 때의 두께 환산량 | nm |

내부 계산은 SI 단위를 사용한다. 화면의 °C는 K로, µm는 m로, nm⁻²는 m⁻²로 변환한다. 공간 출력은 셀 중심이며 첫/마지막 점은 정확한 입구/끝면 값과 다르다.

## 3. 식과 구현 가정

**챔버:** 밸브 입력 분압 u와 실제 분압 P 사이를 일차 지연으로 근사한다.

```text
dP_i/dt = (u_i − P_i) / τ_i
```

공급 중에는 설정 응답 시간, 공급 차단 후에는 배기 응답 시간을 쓴다. 공급 장치·펌프·챔버의 상세 유동을 풀지 않는다. 웨이퍼의 작은 채널이 챔버 전체 분압을 바꾸는 피드백도 생략한다.

**수송:** Knudsen 한계에서 넓은 슬릿의 수력 직경은 약 2H다. 평균 열속도와 확산계수는 다음처럼 계산한다.

```text
v_i = sqrt(8 k_B T / (π m_i))
D_i = (2H / 3) v_i
```

경계 조건은 p_i(0,t)=P_i(t), ∂p_i/∂x(L,t)=0이다. 초기 분압, θ, z는 모두 0이다. 큰 기상 충돌 효과, 캐리어 가스, 점성 유동을 풀지 않으므로 모델의 Knudsen 가정은 실제 총압·충돌 단면적을 아는 경우 별도로 확인해야 한다.

**표면:** A가 빈 자리에 반응하고 B가 A 종결 자리를 전환하는 일반적인 두 상태 근사다.

```text
k_i = s_i(T) / [q sqrt(2π m_i k_B T)]        [Pa⁻¹ s⁻¹]
r_A = k_A p_A (1−θ)                         [s⁻¹]
r_B = k_B p_B θ                             [s⁻¹]
dθ/dt = r_A − r_B
dz/dt = r_B
∂p_i/∂t = D_i ∂²p_i/∂x² − (2q k_B T / H) r_i
film(x) = g_sat z(x)
```

기체 반응 소모와 표면 반응률에 같은 r_i를 사용한다. 표면 자리당 A 한 개와 B 한 개가 관여한다는 단순화이며 실제 반응식의 화학양론을 재현하지 않는다. 잘 분리된 충분한 A/B 주입에서 z≈1로 포화한다. 두 반응물이 동시에 남으면 A→B→A 전환이 반복되어 z가 1을 넘을 수 있다. 이는 이 가정 안의 표면 turnover 결과이며, 실제 CVD 속도 또는 불순물 농도를 검증한 계산이 아니다.

온도에 따른 반응 확률은 200 °C 기준 Arrhenius 보정으로 정한다.

```text
s_i(T) = s_i(T_ref) exp[−E_a/k_B (1/T − 1/T_ref)]
```

T_ref=473.15 K다. 활성화 에너지 입력은 eV에서 J로 변환한다. 탈착·응축·열분해를 생략하므로 온도 상승이 언제나 실제 공정을 개선한다는 의미가 아니다. **플라즈마 전자 밀도·전자 온도·시스·라디칼 반응은 이 열 ALD 모듈에 포함되지 않는다.**

## 4. 무엇이 근거이고 무엇이 가정인가

Knudsen 수송과 Langmuir 흡착을 결합하는 접근 및 기체 소모항의 형태는 [Ylilammi, Ylivaara & Puurunen (2018), DOI 10.1063/1.5028178](https://doi.org/10.1063/1.5028178)의 식 4, 10, 11, 14, 16을 참고했다. [저자 기관 공개 논문](https://acris.aalto.fi/ws/portalfiles/portal/21780044/CHEM_Ylilammi_et_al_Modeling_growth_2018_Journal_of_Applied_Physics.pdf)에서 확인했다. 이 구현은 논문의 해석 근사나 피팅 결과를 그대로 구현한 것이 아니다.

[Aalto의 DReaM-ALD 소개](https://zenodo.org/records/7759195)는 관련 선행 구현이다. 해당 코드나 논문 PDF를 저장소에 복제하지 않았다. 두 상태 반응 확장, 챔버 지연, 이상 주입과 수치 구현은 이 프로젝트에서 독립적으로 작성했다.

분자량 72 u / 18 u, 자리 밀도, 부착 확률, 활성화 에너지, 포화 성장 환산값, 분압, 응답 시간은 **교육용 가정/조절값**이다. 72/18은 익숙한 전구체·공반응물 크기를 상상할 수 있도록 둔 값일 뿐, 실제 TMA/H₂O 화학·중합체 상태·부산물·막 밀도를 식별한 모델이 아니다. 서로 다른 재료 모델을 선택한 것처럼 표시하지 않는다.

## 5. 이상과 해석

| 이상 | 내부에 적용되는 변화 | 먼저 볼 결과 |
| --- | --- | --- |
| 전구체 공급 저하 | A 목표 분압 × (1−강도) | A 분압, 표면 포화, 깊이별 두께 |
| 배기 응답 지연 | 배기 시정수 × (1+8×강도) | 잔류 분압, A/B 중첩, 과도한 표면 turnover |
| 히터 온도 하락 | T_actual = T_set − 60×강도 °C | 유효 반응 확률, 확산계수, 부족 노출에서의 성장 |

배기 이상이 생긴 상태에서 퍼지를 늘리는 것은 잔류를 줄이는 **모델 내 보상 실험**이다. 장비 정비가 해결되었다는 의미는 아니다. 공급 부족에서는 입구 쪽 두께가 유지되면서 깊은 곳만 저하될 수도 있다. 한 KPI만 보고 원인을 단정하지 않고 압력 이력·피복률·깊이별 두께를 함께 비교한다.

`overlap_pa_s = ∫min(P_A,P_B)dt`는 분압 중첩 지표다. 경고에 쓰는 0.02 Pa·s, 잔류 분압 0.01 Pa, 잔류 피복률 0.02, 간격 변화 10%는 해석을 돕는 **프로젝트의 휴리스틱 기준**이고 공정 합격 기준이나 문헌의 범용 임계값이 아니다.

중첩 적분은 일차 챔버 응답의 해석식을 적응형 구적으로 적분한다. 그래프용 표본 사이의 빠른 중첩을 놓치지 않도록 별도로 계산하며 그래프 자체는 단계당 48구간으로 표시한다.

## 6. 수치 계산과 검증 범위

36개 균일 셀의 유한체적 이산화, 입구 반 셀 Dirichlet 조건, 끝면 무유속 조건을 사용한다. SciPy BDF로 각 단계를 적분하며 rtol=2e−7, atol=1e−9다. 비정상적인 피복률·압력을 발견하면 유효 범위를 검사하고 큰 위반은 오류로 처리한다. 수치 결과를 조용히 잘라 물리 범위에 억지로 맞추지 않는다. 적분 오차 수준의 아주 작은 음수는 남을 수 있다.

재현 명령:

```shell
python -m unittest sim_app.tests.test_ald -v
```

검증 항목은 무주입 무성장, 장시간 분리 주입의 포화, 해석적 챔버 배기 응답, 명시된 반복 선형성, 상류 이상 영향·퍼지 보상, 피복률 범위, 입력 오류, 시간 오차 허용치 및 공간 격자 세분화다. 고정 예제의 격자 확인은 모든 파라미터 조합에 대한 수렴 보증이 아니다. 날카로운 반응 전선에는 더 촘촘한 격자가 필요하다.

실험 데이터와의 오차 평가, 실제 장비 레시피 재현, 막 조성·유전 특성·응력 예측, 다중 사이클 형상 진화는 **미검증/미구현**이다. 지원서에는 “반응·수송을 결합한 축약 모델을 구현하고 수치·극한 사례를 검증했다”는 범위로 설명할 수 있다.
