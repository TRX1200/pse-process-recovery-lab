# Process Studio — ALD / Etch Simulator

Python의 공정 모델을 직접 조작하는 로컬 웹 애플리케이션입니다. 레시피와 장비 상태를 바꾸고, 계산 결과를 비교하고, 고장을 주입한 뒤 조치의 효과와 부작용을 확인합니다.

## 무엇을 계산하는가

| 모듈 | 계산 | 결과와 범위 |
| --- | --- | --- |
| Thermal ALD | 챔버 분압의 시간 응답 + 1D 채널 확산 + A/B 표면 반응 | 분압·피복률·한 사이클 성장·깊이별 두께 |
| Plasma Etch | Ar 입자/에너지 수지 + 가상 반응종 수지 + 표면 피복률 변화 | 전자 밀도/온도·이온 에너지·식각 깊이·마스크 손실 |

ALD의 총 두께는 **계산한 첫 사이클 × 반복 횟수**의 투영입니다. 채널이 성장에 따라 좁아지는 현상과 사이클 사이에 잔류 상태가 누적되는 현상은 풀지 않습니다. Etch의 방사형 깊이 분포는 **가정한 이온 플럭스 분포**를 표면 모델에 넣은 결과입니다. 패턴의 2D/3D 측벽 진화를 계산한 것이 아닙니다.

각 식, 단위와 가정은 [ALD 모델](ALD_MODEL.md), [Etch 모델](ETCH_MODEL.md)에 기록합니다. 두 모듈은 독립 가상 실험입니다. ALD로 만든 실제 재료가 Etch 모듈로 자동 연계되는 공정 통합 모델이 아닙니다.

v0.3에서는 **수식·원리** 탭에 구현한 방정식과 현재 값을 표시합니다. **공정 평가** 탭에서는 사용자 목표와 종점 결과를 비교하며, 평가 불가 항목과 다음 확인 실험을 함께 보여줍니다. 규격·결과·비교 기준·메모를 포함한 별도 평가 JSON을 내보낼 수 있습니다. [평가 규칙과 PSE 연습 사례](PROCESS_ASSESSMENT_KR.md)를 먼저 읽으세요.

## 직접 조절하는 항목과 계산되는 상태

- 레시피: 주입·퍼지 시간, 전구체 분압, 온도, 사이클 수 / 전력, 압력, 유량, 반응 가스 분율, 바이어스, 처리 시간.
- 장비: 채널과 챔버 형상, 응답 시간 / 전력 전달 효율, RF 반사율, 벽 손실.
- 고급 모델 계수: 부착 확률, 자리 밀도, 성장 환산량 / 유효 충돌 단면적, 반응 수율, 반응 문턱 등.
- 계산 상태: ALD 표면 피복률과 분압 분포 / Etch 전자 밀도·온도, 이온·라디칼 플럭스.

고급 계수는 가정을 탐구하는 입력입니다. 실제 장비에서 모두 독립적으로 조절할 수 있는 레시피 항목이라는 뜻은 아닙니다. 모든 컨트롤은 단위·허용 범위·설명을 API 스키마에서 가져옵니다.

## 고장이 결과로 이어지는 경로

ALD: 전구체 공급 저하 → 실제 A 분압 감소. 배기 응답 지연 → 가스 제거 시정수 증가. 히터 편차 → 실제 온도 감소.

Etch: RF 매칭 이탈 → 실제 반사율 증가. 압력 편차 → 실제 압력 변화. 반응 가스 공급 저하 → 실제 유입량 감소. 벽 상태 변화 → 라디칼 손실 증가.

불량 KPI를 사전에 지정하지 않고 변경된 상류 상태로 모델을 다시 계산합니다. 고장 시 비교 기준은 **같은 레시피에서 고장을 주입하지 않은 계산**입니다. 실제 측정 정답이나 다른 장비의 검증값이 아닙니다.

## 첫 두 가지 실험

### Run simulation과 시간 재생

1. 현재 레시피·고장 조건으로 Python이 시간 응답과 공간 프레임을 계산한 뒤 브라우저가 결과를 받습니다.
2. `t=0`부터 반응기·시간 그래프·현재 수치를 함께 재생합니다. 오른쪽 Model results는 종점/정상상태 결과이며, 현재 시각의 수치는 재생 패널에서 읽습니다.
3. 일시정지와 슬라이더로 임의 시각을 확인합니다. 1×는 실제 1초당 공정 1초입니다. 속도를 바꿔도 물리 결과나 해석기의 시간 간격은 변하지 않습니다. ALD 기본은 0.5×, Etch 기본은 5×입니다. 메뉴 이동·창 숨김·다음 계산 동안 재생을 멈춥니다.

| 화면 표현 | 계산되는 것 | 계산하지 않는 것 |
| --- | --- | --- |
| ALD 시간 그래프·채널 막 | 챔버 분압, 피복률, 첫 사이클의 셀별 성장 | N개 사이클을 연속으로 푼 형상 진화 |
| Etch 시간 그래프·웨이퍼 표시 | 고정 정상 플라즈마 아래 표면 피복률과 식각량 | 점화·소멸, RF 파형의 시간 응답 |
| 보라색 플라즈마·움직이는 입자 | 평균 밝기는 계산 전자밀도의 시각적 단서 | 실제 발광 세기·궤적·진동 주파수. 일렁임과 이동 자체는 설명용 효과 |

공간 프레임은 계산한 중간 상태이며 표본 사이를 선형 보간합니다. 최종 형상을 단순히 `t/T`로 늘리지 않습니다. 시간축 그래프만 함께 펼칩니다. 입자 수지·에너지별 수율·종점 공간 분포에는 시간축이 아닌 정적 그림임을 표시합니다. 반응기 안의 형상 변화는 가독성을 위한 확대 표현으로 실제 축척이 아닙니다.

첫 재생 실험은 Etch 600 W·60 s를 실행하고 5×로 보는 것입니다. 전자밀도·온도는 일정하고 식각량만 증가하는지 봅니다. 900 W로 바꾸어 다시 실행하면 새 정상 플라즈마 조건의 식각 진행을 비교할 수 있습니다. ALD는 0.5×에서 A 주입·퍼지·B 주입·퍼지와 분압 변화를 관찰합니다.

화면의 **Simulate**는 한 레시피 실행, **Sweep**는 한 입력의 범위 탐색, **Recipes**는 저장한 조건과 실행 기록, **Model notes**는 가정과 적용 범위입니다. 입력을 바꾼 뒤 Run simulation을 눌러야 새 결과를 계산합니다. 기존 결과에는 마지막 실행의 조건이 적용됩니다.

Save recipe는 현재 입력을 브라우저에 저장합니다. Export의 Recipe JSON은 다시 불러올 조건, Run JSON은 모델 버전·입력·결과·실험 메모, CSV는 수치 분석용 데이터입니다. 브라우저별 저장 공간은 별개입니다. 파일 내보내기는 Chrome에서 확인했으며, 내장 브라우저에서 다운로드가 되지 않으면 같은 로컬 주소를 Chrome으로 열어 사용합니다.

범위 밖 계산과 분모가 0인 비율은 화면과 CSV에서 유효한 0으로 표시하지 않습니다. 비교 기준이 거의 0인 경우 퍼센트 대신 단위가 있는 차이를 표시합니다. 그래프와 표는 표시를 위해 반올림하며 JSON에는 원래 수치가 보존됩니다.

**ALD 배기 문제:** 정상 실행 → 배기 응답 지연 선택 → 분압 중첩과 깊이별 두께 확인 → 고장을 유지한 채 퍼지 시간을 늘림 → 분압 중첩이 줄어드는지와 사이클 시간이 얼마나 길어지는지 함께 확인합니다. 잔류가 큰 경우 첫 사이클 × N 두께 투영의 한계도 기록합니다.

**Etch RF 전달 문제:** 정상 실행 → RF 매칭 이탈 선택 → 실제 반사율·흡수 전력·전자 밀도·식각량 비교 → 고장 강도를 0으로 되돌려 계산상 전달 상태 복구 → 깊이와 마스크 손실을 함께 확인합니다. 고장 강도를 되돌린 것은 알고 있는 모델 상태를 복원한 것이며 실제 장비 수리나 원인 규명의 증거로 표현하지 않습니다.

화면의 정상/고장 비교와 별개로, 한 입력을 여러 값으로 바꾸는 조건 탐색을 통해 민감도를 확인합니다. 이것만으로 다인자 DOE나 공정 최적화가 끝난 것으로 표현하지 않습니다.

## 실행

Python 3.10 이상, Node.js 22.12 이상, pnpm을 사용합니다. 저장소 루트에서 다음을 실행합니다.

```powershell
python -m pip install -r sim_app/requirements.txt
cd sim_app/frontend
pnpm install --frozen-lockfile
pnpm build
cd ../..
python sim_app/server.py
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 계산은 로컬 Python에서 수행하며 모델 API 키가 필요하지 않습니다.

검증과 그림 없이 결과를 재생성하는 명령:

```powershell
python -m unittest discover -s sim_app/tests -v
python sim_app/run_reference_cases.py --out outputs/process_studio/reference_cases
```

생성 JSON에는 모델 버전, 입력, 고장, 내부 상태, 시계열과 비교 기준이 들어갑니다. CSV는 지표 비교용입니다. 생성 시각은 실행마다 달라지며, run_id는 모델 버전·입력·고장으로 결정됩니다.

2026-09-28 구현 검증: Python 수치·API 테스트 41개, 프런트엔드 입력·표시·CSV·재생 테스트 11개 통과. TypeScript/Vite 빌드 통과. 실행 환경은 NumPy 2.1.3, SciPy 1.18.0, Node 24.19.0입니다. 의존성 범위의 모든 버전 조합을 시험한 것은 아닙니다.

브라우저에서는 1401×912 데스크톱과 390×844 모바일 폭에서 화면·실행 조작을 확인했습니다. 전력 변경, RF 고장 비교, ALD 퍼지 회복, 스윕의 범위 밖 값 제외, 저장·불러오기 및 모델 설명을 확인했습니다. Chrome에서 실제 JSON·CSV 저장 파일을 읽어 확인했습니다. 파일 선택을 통한 JSON 가져오기 전체 동작은 자동화 도구의 파일 선택 제한으로 미확인이고, 입력 검증은 단위 테스트로 확인했습니다.

v0.2 시간 재생은 실제 캡처 기준 1401×912 데스크톱과 375×812 모바일 화면에서 추가 확인했습니다. 실행 시 처음부터 재생, 일시정지, 시간 이동, 종점 이동, 같은 레시피 재실행, 재생 속도 유지, ALD 단계 전환과 플라즈마 전력 0 조건을 확인했습니다. 브라우저 오류·경고 로그는 없었습니다. 이는 소프트웨어 동작 검증이며 실제 장비의 시간 응답 검증은 아닙니다.

v0.3 검증: Python 41개·프런트엔드 19개 테스트와 TypeScript/Vite 빌드를 통과했습니다. 참고 사례 8개/지표 73행을 재생성했습니다. 내장 브라우저의 1280×720 데스크톱·실제 캡처 375×812 모바일에서 평가표와 수식을 확인했고, 모바일 탭의 페이지 가로 넘침을 수정했습니다. 규격 수정 전후 판정, 저장 후 새로고침, 잘못된 허용 편차 거부, RF 고장과 정상 비교, ALD 평가를 조작했습니다. Chrome에서 평가 보고서 JSON을 내려받아 원 실행·모델 버전·규격·현재 판정·비교 판정을 파일로 확인했습니다. 최종 화면의 오류·경고 로그는 없었습니다. 평가 보고서의 브라우저 다운로드는 Chrome에서 검증했습니다.

## 지원서에서 설명할 수 있는 범위

모델 구현과 수치 검증은 공정 원리를 코드로 표현한 근거입니다. 실제 공정 정확도를 말하려면 별도의 문헌 곡선 재현·독립 실험 데이터 비교가 필요합니다. 현재 모델 계수는 특정 Applied Materials 장비나 고객 레시피에 맞춰 보정하지 않았습니다.

본인이 실험하고 이해한 뒤 사용할 소개 문장 예시:

> ALD와 플라즈마 식각의 공정 원리를 학습하기 위해 Python 기반 축약 시뮬레이터를 구현했습니다. ALD의 수송·표면 반응과 식각의 플라즈마 수지를 연결하고, 공급·배기·RF 전달 이상을 주입해 관측 변화와 조치의 영향을 비교했습니다.

그다음 문장은 직접 수행한 실험으로 채웁니다: **어떤 현상 → 경쟁 가설 → 선택한 확인 → 실제 계산 결과 → 남은 한계.** AI 도구의 구현 지원과 본인이 검토한 모델·실험·해석을 구분하여 설명합니다.
