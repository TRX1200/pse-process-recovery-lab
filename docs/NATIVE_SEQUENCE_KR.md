# 물리 연속공정: Si Etch → Strip → Al₂O₃ ALD

## 이번에 바뀐 것

`물리 연속공정`은 하나의 ViennaPS 2D domain에서 식각한 결과를 유지하고,
마스크를 제거한 뒤 그 표면에 ALD를 계산한다. 앞 단계의 깊이만 읽어 직사각형
홈으로 다시 만드는 방식이 아니다. 식각된 측벽 경사와 바닥 모양도 다음 단계에 전달된다.

기존 GAA/게이트 예제는 `구조 설계`에 있다. 지정 두께와 선택비를 사용하는 기하학 모델이며,
이번 반응·수송 모델과 임의의 재료 조합으로 연결되지 않는다.

## 시작

저장소 루트에서 다음을 실행한다. Windows Python 환경에는
`native_lab/requirements.txt`의 고정 버전을 설치해야 한다.

```powershell
.\START_RF_LAB.ps1 -Port 8769
```

브라우저: <http://127.0.0.1:8769/#process>

1. 왼쪽 `공정 조건`의 레시피 선택에서 증착 조건을 불러온다. 이미 계산된 결과는 우측 상단 `계산 예제`에서 연다.
2. `빠른 조절`에서 사이클, TMA 노출·분압, 온도, 개구 폭, 식각 시간, 이온 에너지·방향성을 바로 바꾼다. 숫자 입력, ± 버튼, 슬라이더가 같은 입력을 편집한다.
3. 나머지 항목은 같은 설정창의 `구조 / 식각 / ALD / 수치` 버튼으로 선택한다. 여섯 개를 넘으면 다음 페이지 버튼을 사용한다. 항목의 `?` 또는 입력칸을 누르면 해당 설명과 허용 범위가 아래에 나온다.
4. 설정창 맨 아래 `연속 공정 계산`을 누른다. `계산값으로 되돌리기`는 입력을 현재 표시된 완료 결과의 값으로 복원한다.
5. 결과 영역 상단의 식각 / 마스크 제거 / ALD 버튼으로 단계별 단면을 본다. `현재 결과 비교 고정` 후 조건을 바꿔 다시 계산한다.
6. `결과 저장`에서 SVG / CSV / 전체 JSON을 저장한다. 이전 로컬 결과는 `실행 기록`에서 연다.

휴대폰에서는 `조건 조절 / 단면·결과` 버튼으로 화면을 전환한다. 낮은 화면에서는
슬라이더를 생략하고 숫자·± 입력을 유지한다. 긴 모델 설명과 예외적으로 좁은 화면에는
패널 내부 스크롤을 허용하지만, 일반 설정과 실행 버튼은 한 화면에서 다룬다.

화면은 새 계산 중에 직전 완료 결과를 유지하고 진행률을 별도로 표시한다.
변경한 입력이 아직 계산에 반영되지 않으면 안내 문구가 뜬다.
공개 GitHub Pages에서는 저장된 계산 예제와 비교/내보내기를 사용할 수 있으며,
새로운 native 계산에는 로컬 Python 서버가 필요하다.

## 계산 범위

| 단계 | 모델 | 전달/갱신 내용 |
|---|---|---|
| Si 식각 | ViennaPS SF6O2Etching | 이온/F/O 수송, 표면 피복, 제거 속도, level set |
| 마스크 제거 | 이상적인 Boolean 제거 | 유효 마스크 영역 제거, Si 형상 유지 |
| Al₂O₃ ALD | ViennaPS SingleParticleALD | TMA 제한 반응, 재반사, 자리 피복률, 성장 |

좌표는 x 수평, y 위쪽 +, 엔진 길이 µm, 출력 nm다. 좌우는 반사 경계, 세로는 무한 경계다.
식각의 시간축은 초, ALD의 축은 사이클이다. 제거 단계는 처리 시간을 모델링하지 않는다.
단계들을 하나의 초 단위 시간축으로 이어 붙이지 않는다. 재생 간격 0.5초는 UI 설정이다.

식각에서 생성한 domain을 유지한다. MakeTrench는 `[Mask, Si]`의 순서로 level set을 저장하고,
Si level set에는 마스크 영역도 감싸져 있다. 따라서 `removeLevelSet(0, True)`로 마스크 체적을
제거한 후, `duplicateTopLevelSet(Al2O3)`로 성장층을 추가한다. `removeTopLevelSet`으로
마스크를 제거하면 오히려 Si를 지우므로 사용하지 않는다.

ALD의 상단/바닥 막 두께는 저장된 Si 경계에 대한 수직 높이 차다. 상단은 x=0.4×영역 폭,
바닥은 x=0에서 측정한다. 측벽 법선 두께나 웨이퍼 전체 균일도는 아니다.
중간/최소 통로 폭은 원래 Si 상단과 바닥 사이의 수평 절단선에서 측정한다.
깊이가 2격자 이하이면 통로를 측정 불가로 둔다. 최소 통로는 유한한 샘플 위치의 값이다.
초기 막 두께가 0이면 바닥/상단 비율은 정의되지 않아 화면과 CSV에서 비워 둔다.

막 두께가 2격자보다 작으면 화면에 해상도 주의를 표시한다. 레벨셋이 격자 이하 경계를
표현할 수 있어도 정량 정확도가 검증되었다는 뜻은 아니다. 거친 격자의 작은 두께 차이나
미세 요철을 물리적 결함으로 판단하지 않는다.

## 먼저 할 비교

추가 실험은 `증착 실험 10` 탭에서 고른다. [ALD 10개 실험 설명서](ALD_EXPERIMENTS_KR.md)에
입력 조합, 비교 대상, 기록법을 정리했다. 이들은 입력 프리셋이며 아래 저장된 계산 예제와 구별한다.

기준: 식각 5 s, 100 nm 개구, 격자 5 nm, 표면점당 300 rays, 이온 방향성 지수 500,
ALD 160 cycles, TMA 노출 0.05 s. 나머지 값과 seed는 각 결과의 `request.params`가 기준이다.

| 비교 | 변경한 값 | 확인할 것 |
|---|---|---|
| 이온 입사각 | 방향성 지수 500 → 20 | 깊이, 절반 깊이 폭, 측벽 경사, 뒤따르는 ALD 단면 |
| 공급 부족 | TMA 노출 0.05 → 0.001 s | 막 두께와 바닥/상단 비율, 격자 의존성 |
| 수치 민감도 | grid / rays / seed 중 한 개씩 | 효과 크기와 수치 차이 구분 |

공급 부족 예제의 막은 5 nm 격자보다 얇다. 반응 경향을 보는 예제이며 해당 nm 수치나
피복률을 검증된 예측으로 보고하지 않는다. 결과 보고서에는 해상도 제한을 같이 적는다.

## 재현 / 검증

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s native_lab/tests -v
.\.venv\Scripts\python.exe -m native_lab.build_sequence_examples
```

첫 명령의 연속공정 검사는 다음을 포함한다.

- 제거 후 Si 경계와 ALD 초기 Si 경계의 일치
- ALD 동안 Si 경계 고정, 노출이 0이면 막 성장 없음
- 식각 시간이 0이면 식각 형상 고정, 마스크 제거 후 실제 Si 상단 복원
- 고정 seed 재실행과 노출 감소에 따른 성장 감소
- 잘못된 입력 거부, subprocess 완료와 단계별 파일 저장

공개 예제 재계산은 두 번째 명령으로 수행한다. 생성된 JSON에는 입력, 엔진/코드 버전,
소스 SHA-256, 단계별 전체 단면, geometry handoff hash가 들어간다. 로컬 작업은
`outputs/native_lab/<run-id>/` 아래에 저장되며 `01_etch`, `03_ald`에는 native surface/level-set
파일도 보관한다. 테스트 통과는 소프트웨어/수치 계약 확인이며 실제 장비와의 일치 증거는 아니다.

## 아직 계산하지 않는 것

- 마스크 strip 화학, 유한 선택비, 기판 손상
- 단계 사이 표면 termination/잔류물/자연 산화막/ALD nucleation 지연
- ALD 전체 반응망, 비이상 purge, 불순물, 온도에 따른 반응계수 변화
- RF 회로/챔버 압력/유량에서 입사 플럭스를 만드는 reactor 모델
- HfO₂, TiN, SiGe 선택식각을 포함한 실제 GAA 전체 공정
- 도핑, 접촉, Poisson/수송 방정식, Id–Vg/Id–Vd

현재 연결은 **형상 이력의 전달**이며 표면 화학 상태의 연속 전달이 아니다.
추가 재료와 소자 해석을 지원하려면 각 재료의 반응 모델과 독립 검증 자료가 필요하다.

## 출처와 기여

해석기는 [ViennaPS 4.6.2](https://github.com/ViennaTools/ViennaPS/tree/v4.6.2)와 ViennaLS다.
마스크 제거/성장층 API의 의미는 해당 버전의
[Domain 구현](https://github.com/ViennaTools/ViennaPS/blob/v4.6.2/include/viennaps/psDomain.hpp)을 확인했다.
반응·수송 모델의 참고 문헌과 계수 해석은 [기존 native 설명서](NATIVE_SIMULATOR_KR.md)에 있다.
이 저장소에서 구현한 부분은 Python 공정 연결, 입력 검증, 형상 전달 검증, 계측,
UI, 비교/내보내기 및 재현 가능한 예제다. 외부 해석기를 직접 개발했다거나 장비 검증을 마쳤다고 표현하지 않는다.
