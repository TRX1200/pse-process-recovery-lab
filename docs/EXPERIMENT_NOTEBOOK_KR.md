# ALD / Etch Lab — 실험 노트

이 프로젝트의 목적은 RF 배경에서 ALD·Etch의 공정 입력, 내부 상태, 결과를 연결해 공부하고 그 과정을 재현 가능한 기록으로 남기는 것입니다. 지원자가 직접 설명할 대상은 화려한 화면보다 **모델을 선택한 이유, 가설, 비교 조건, 결과 해석, 아직 모르는 것**입니다.

## 사용 순서

1. Plasma Etch 또는 Thermal ALD를 선택하고 고정 조건·변경 조건을 읽습니다.
2. 계산 전 가설을 씁니다. 어떤 지표가 왜 변할지 예상합니다.
3. 비교 실험을 계산합니다. 기준·이상·조치 가설은 각각 Python으로 계산합니다.
4. 표에서 여러 지표와 프로젝트 규격을 확인하고 시간 응답을 봅니다.
5. 결과의 실행 ID를 눌러 입력을 직접 바꾸거나, 수식·공정 평가로 들어갑니다.
6. 해석을 쓰고 전체 JSON과 보고서 MD를 내려받습니다. 실제 장비에서 추가로 확인해야 할 로그도 적습니다.

비교 실험은 모델 기본값에서 시작합니다. 레시피 실험 화면에서 편집 중인 조건을 암묵적으로 가져오지 않습니다. 이상 강도나 조치 입력을 바꾸면 마지막 계산 결과임을 알리는 문구가 표시됩니다. 메모는 브라우저에 저장되며 결과 파일은 직접 내려받아 보관합니다.

## Etch: RF 전달 손실과 보상 가설

기준은 소스 전력 600 W, 압력 20 mTorr, 바이어스 크기 120 V, 처리 시간 60 s입니다. 반사율 0.04, 결합 효율 0.75, 듀티 1에서 흡수 전력은 432 W입니다.

이상 강도 0.35는 실제 반사율을 0.04 + 0.96 × 0.35 = 0.376으로 만듭니다. 설정 전력은 그대로이고 흡수 전력은 280.8 W로 감소합니다. 세 번째 조건은 이 이상을 유지하면서 설정 전력만 바꾸는 가설입니다. 기본 입력은 600 / 0.65를 소수점 둘째 자리까지 표시한 923.08 W입니다.

**해석의 핵심:** 현재 모델은 반사 증가를 흡수 전력 손실로만 전달합니다. 따라서 흡수 전력이 같아지면 다른 응답이 거의 복원되는 것은 모델 구조에서 예상되는 결과입니다. 이를 실제 장비에서 전력만 올리면 고장이 해결된다는 결론으로 확장할 수 없습니다. 실제 점검에는 RF 전력·매칭 위치·압력·유량 이력과 장비 절차가 필요합니다.

표의 식각 깊이는 가정한 방사형 분포의 면적 평균입니다. 그래프는 균일 플럭스에서의 타깃 제거량입니다. 평균 방식이 다르므로 두 수치를 같은 관측값으로 혼동하지 않습니다.

## ALD: 배기 지연과 퍼지 연장

기준은 A/B 주입 각 0.5 s, 각 퍼지 1.5 s, 온도 200 °C, 첫 사이클 성장의 50회 투영입니다. 기본 배기 시정수 0.15 s가 이상 강도 0.35에서 0.57 s로 늘어납니다. 조치 가설은 지연을 유지한 채 두 퍼지를 각각 3 s로 연장합니다.

2026-10-01 현재 Python 모델로 직접 계산한 이 조건에서는, 퍼지 연장이 이상 조건 대비 중첩과 잔류를 줄여도 예제 규격을 모두 만족하지 못합니다. 첫 사이클 × 50 투영 두께 약 5.6713 nm, 깊은 곳/입구 두께비 약 88.2867%, 중첩 약 0.056786 Pa·s, 종료 잔류 약 0.15004 Pa, 사이클 7 s입니다. 이 값은 실측이 아니라 해당 모델·입력의 계산입니다.

**해석의 핵심:** 한 지표의 개선이 공정 전체의 성공은 아닙니다. 더 긴 퍼지는 시간 비용이 있으며, 두께만으로 반응 분리나 깊이 방향 성장을 판단할 수 없습니다. 분압 중첩 지표를 실제 불순물 농도로 읽지 않습니다. 실제 검증에는 압력 감쇠 로그와 막 두께·조성 측정 등이 필요합니다.

세 조건의 시간이 다르면 각 원래 시각의 합집합으로 표시용 선형 보간합니다. 짧은 사이클 종료 이후를 임의로 연장하지 않습니다. JSON에는 원래 시계열을 보존합니다.

## 근거와 범위

- 실행 JSON: 전체 입력, 고장 설정, 모델 버전, 실행 ID, 계산 상태, 원래 시계열.
- 보고서: 계산값, 현재 평가 기준, 사용자가 작성한 가설·해석. 작성하지 않은 부분은 미작성으로 표시합니다.
- 수식: Python 구현과 대응하는 KaTeX 수식, 변수 단위, 마지막 계산값, 모델 명세 링크.
- 검증: 입력 경계·보간·수식 렌더링·브라우저 동작 검사는 소프트웨어 검증입니다. 실제 장비 정확도 검증과 구분합니다.

장비 로그 수집, 실측 데이터 기반 이상 분류, 원인 식별 정확도, 유지보수 예측 모델은 현재 구현 범위가 아닙니다. 이 도구는 그러한 분석에 앞서 입력–상태–결과의 연결과 어떤 데이터가 필요한지를 공부하는 출발점입니다.

Python 모델과 화면 구현에 AI 도구의 지원을 사용했습니다. 직접 수행한 학습과 판단은 작성한 실험 노트로 증빙합니다. 아직 작성하지 않은 해석을 지원자의 수행 실적으로 주장하지 않습니다.
