# Process Lab: 2D 연속공정과 가상 계측

2026-10-14 / process-flow-0.1.0

## 지금 할 수 있는 일

공정 단계를 편집하고 앞 단계의 재료와 형상을 다음 단계로 넘깁니다.
GAA 게이트를 가로지르는 2D 단면, 평면 게이트와 spacer 전구 구조를 계산합니다.
그림을 순서대로 교체하는 애니메이션이 아니라, 각 연산이 직전 재료 격자에 적용됩니다.
부분 실행은 입력 레시피의 처음부터 선택 단계까지 다시 계산하며, 저장 프레임을 단순 변형하지 않습니다.

이 모듈은 Python/NumPy/SciPy로 구현한 기하학적 공정 모델입니다.
기존 ALD / Etch 탭의 ViennaPS 입자 수송·표면 반응·level-set 계산이나 RF 모델과 자동 결합하지 않습니다.
공정 순서·선택비·접근 가능한 표면·형상과 계측의 관계를 학습하는 범위입니다.

## 실행과 화면

저장소의 기존 `.venv`와 프런트엔드 빌드를 사용합니다. 기존 설치 안내는
[Native 설명서](NATIVE_SIMULATOR_KR.md), [RF 설명서](RF_MATCHING_KR.md)를 참고하세요.

```powershell
.\.venv\Scripts\python.exe -m rf_lab.server --port 8768
```

브라우저에서 `http://127.0.0.1:8768/`을 엽니다. 해당 포트에 구버전 서버가 실행 중이라면
종료 후 다시 실행하거나 `--port 8769`처럼 비어 있는 포트를 사용하세요.
새 API는 `/api/flow/schema`, `/api/flow/simulate`입니다.
GitHub Pages는 저장 예제 뷰어이며 로컬 서버 없이 새 연속공정을 계산하지 않습니다.

1. 상단에서 GAA / 평면 게이트 예제를 고릅니다.
2. 왼쪽 공정 또는 아래 단계 버튼으로 해당 계산 상태를 확인합니다.
3. 오른쪽에서 두께·폭·선택비 등을 바꿉니다. 입력이 바뀌어도 이전 결과는 그대로 표시되고 경고가 뜹니다.
4. `선택 단계까지 실행` 또는 `전체 실행`으로 변경 사항을 계산합니다.
5. `계측` 탭에서 단면을 클릭하거나 위치를 입력합니다. `치수 / 목표`와 `SEM 신호`를 전환합니다.
6. 레시피 JSON, 결과 JSON, 현재 단면 SVG, 계측 CSV를 저장합니다.

데스크톱은 왼쪽 공정 / 중앙 단면 / 오른쪽 조건을 유지합니다.
좁은 화면에서는 공정 순서 / 단면·계측 / 조건 설정 버튼으로 한 패널씩 열립니다.
ALD / Etch 결과도 단면 / 목표 / 평가 / 그래프로 나누었고, RF 회로는 전력 / 매칭 / 응답 / 비교로 나누었습니다.

## 좌표·수치 규약

| 항목 | 규약 |
| --- | --- |
| 좌표·단위 | x 수평, z 위쪽, nm. 초기 기판 표면 z=0 |
| 격자 | 정사각 셀, 셀 중심의 재료 분류, 한 셀에 한 재료 |
| 기본 영역 | x=-160~160 nm, z=-60~180 nm, 간격 2 nm |
| 경계 | 하단 한 행 고정, 좌우 주기 경계 없음, 가스는 상단에서 연결 여부 판단 |
| 해상도 | 1~10 nm, 최대 65,536셀 / 24단계. 영역 경계는 격자의 정수배 |
| 두께 양자화 | 적층은 가까운 정수 셀, 방향성 식각은 내림한 셀 수, 증착은 셀 중심 간 거리 |
| 시간 | 단계별 지정 거리/두께. 실제 공정 시간, ALD cycle, RF transient로 환산하지 않음 |
| 확률성 | 형상 계산에는 난수 없음. SEM 잡음만 seed=42 |
| 저장 | `outputs/flow_lab/<run_id>/request.json`, `result.json` |
| 추적 | 입력 해시, 각 단계의 재료·좌표·마스크 해시와 부모 해시, 모델 소스 SHA-256, Python/NumPy/SciPy 버전 |

SVG는 원본 재료 셀을 그리며 격자의 계단 모양을 곡선으로 숨기지 않습니다.
`형상 맞춤`은 단계마다 화면 범위를 맞추므로 외형의 화면상 크기가 바뀔 수 있습니다.
단계 간 고정 축 비교는 이 옵션을 끄세요. x/z 길이 축척은 동일합니다.

## 공정 연산

| 연산 | 계산 | 생략한 물리 |
| --- | --- | --- |
| Si/SiGe 적층 | 평탄한 표면 위 교대 재료 층 생성 | 에피택시 반응, 응력, 결정 결함 |
| 마스크 | 지정한 x 구간의 수직 투영 보호 | 노광/현상, resist 두께·침식, lift-off |
| 방향성 식각 | 노출된 열을 위에서 제거, 다른 재료에 도달하면 정지 | 이온 각도/에너지, charging, microloading |
| 선택 식각 | 접근 가능한 가스에서 시작하는 8방향 가중 최단 경로 | 실제 화학 반응, 수송 제한, 선택비의 공정 의존성 |
| 등두께 증착 | 초기 표면으로부터 거리 offset, 반 격자 간격마다 가스 연결 갱신 | ALD 포화/전구체 고갈, nucleation, 실제 막 조성 |
| 높이 절단 | 지정 z보다 높은 재료 삭제 | CMP 압력/마찰, dishing/erosion |

선택 식각에서 대상 속도는 정규화값 1, 다른 고체는 1/선택비입니다.
입력 거리는 대상 재료에서의 유효 식각 거리입니다. 제거된 가스 공간의 이동 비용은 0입니다.
대각선은 직교 경로와 재료 비용을 고려하지만 8방향 스텐실의 각도 오차가 남습니다.
선택비 100에서 54 nm를 식각하면 다른 재료의 nominal 거리는 0.54 nm이므로
2 nm 격자에서는 실제 형상 손실로 나타나지 않을 수 있습니다. 이를 무한 선택비로 해석하면 안 됩니다.

증착은 처음부터 막힌 공동과, 증착 도중 입구가 닫힌 공동의 추가 코팅을 제한합니다.
연결된 공간 안에서는 이상적인 즉시 수송을 가정하므로 실제 high-AR ALD의 두께 분포는 예측하지 않습니다.
마스크가 남아 있는 상태의 적층·증착·선택 식각·평탄화는 지원하지 않으며 오류로 알려줍니다.

## GAA 예제: 7단계

| 단계 | 기본 입력 | 관찰할 점 |
| --- | --- | --- |
| 1 | SiGe 16 / Si 10 nm, 3회 | 교대 적층 78 nm |
| 2 | 보호 폭 100 nm | 가운데 stack 보호 |
| 3 | 방향성 식각 90 nm, 모든 재료 | 외부 stack 제거와 기판 recess |
| 4 | 마스크 제거 | stack 측면 노출 |
| 5 | SiGe 거리 54 nm, 선택비 100 | SiGe 제거, z≥0에서 분리된 Si 3개 |
| 6 | HfO2 4 nm | Si 주변 절연막 offset |
| 7 | TiN 6 nm | 절연막 밖 금속 형상과 통로 폐쇄 |

이 단면은 채널 축에 수직인 게이트 영역입니다. 떠 있는 Si 시트의 양 끝 고정,
source/drain, inner spacer, replacement gate 전체 공정, 접촉은 해석 영역 밖입니다.
현재 예제의 지지·전기적 연결성을 3D로 입증하지 않았습니다.

## 계측과 판정

수평 절단은 지정 z에 가장 가까운 해당 셀 행, 수직 절단은 해당 x 셀 열을 읽습니다.
표시 좌표는 실제 셀 중심이며, 재료별 연속 구간의 폭은 셀 수 × 격자 간격입니다.
평가 재료의 구간이 하나일 때만 `|측정값-목표| ≤ 허용오차`로 판정합니다.
동일 재료 구간이 여러 개이거나 목표가 유효하지 않으면 평가 불가로 표시합니다.
이 판정은 사용자 기준 비교이며 장비 합격 규격이나 통계적 측정 불확도가 아닙니다.

SEM 표시는 재료별 가정한 대비 → Gaussian PSF → Gaussian 잡음 → 0~1 clipping 순서입니다.
σ는 PSF 폭(nm) / 잡음의 정규화 세기이며 둘은 다른 값입니다.
임계값 폭은 신호가 임계값 이상인 셀들의 길이로, 특정 재료의 CD와 같지 않을 수 있습니다.
전자 산란·2차전자 검출·charging 해석이나 실측 보정은 포함하지 않습니다.
계측 CSV에는 위치, 재료, 신호, PSF, 잡음, seed, 임계값, 목표, 허용오차, 격자, 형상 해시를 함께 남깁니다.

`추이`의 면적은 2D 재료 단면적이며 체적·질량이 아닙니다.
Si 성분 수는 z≥0 격자의 연결 성분 수이며 소자 수·전기적 연결성은 아닙니다.
결과 JSON의 surface_rq_nm는 각 열 최상단 높이의 표준편차이며 패턴 단차도 포함합니다.
따라서 원자 표면 거칠기로 보고하면 안 됩니다.

## 바로 할 비교 실험

1. GAA 5단계에서 거리 20 / 40 / 54 nm를 비교합니다. SiGe 잔류가 없어지는 조건을 확인합니다.
2. 선택비 100 / 10 / 2를 비교해 Si 손실과 잔류 제거 사이의 절충을 봅니다.
3. HfO2 두께 2 / 4 / 8 nm를 비교하고 통로와 금속 연결 형상을 읽습니다.
4. 평면 예제에서 Si3N4 증착 10 nm를 고정하고 etch-back 6 / 12 / 20 nm를 비교합니다.
5. 같은 형상의 가상 SEM에서 PSF·잡음·임계값만 바꾸어 격자 치수와 신호 폭이 왜 다른지 기록합니다.

비교할 때 한 번에 한 조건만 바꾸고 원본 레시피/결과를 함께 저장하세요.
모든 비교 수치는 모델 결과로 표시하고 실제 장비 경험으로 기술하지 않습니다.

```powershell

```

추가된 자동 검증은 평면 증착·식각의 해석적 면적, 마스크 보호, 단계 순서와 부분 실행,
매립 재료 보호, 유한 선택비, 밀폐 공동·증착 중 pinch-off, 1/2/4 nm 평면 한계,
GAA의 SiGe 제거와 3개 Si 성분, 입력 거부, HTTP 결과 저장, 계측 축·단위,
SEM 결정성, CSV의 기초 데이터에 해당하는 셀 폭과 예제 면적 일치를 확인합니다.
이 검증은 구현 일관성과 특정 한계 사례에 대한 것이며 장비 정확도·복잡한 구조의 격자 수렴 검증은 아닙니다.

## CMOS / GAA 트랜지스터로 확장하려면

현재 단계: 재료 구조와 공정 순서, 치수 계측.
다음 단계: 도핑 분포, 산화/확산·열이력, 접촉과 절연 영역, 보존적인 메시 변환,
실제 소자 단면의 경계조건을 정의합니다.
그 다음: Poisson과 전자/정공 수송 방정식, 재결합·이동도 모델을 검증된 소자 해석기에 연결하고
MOS capacitor의 해석적 한계 → nMOS/pMOS Id–Vg → CMOS 인버터 순으로 검증합니다.
GAA는 3D 구조와 양자 구속을 포함한 추가 모델·검증이 필요합니다.
현재 결과를 완성된 트랜지스터, Silvaco 대체품, 장비 보정 TCAD라고 부르지 않습니다.
