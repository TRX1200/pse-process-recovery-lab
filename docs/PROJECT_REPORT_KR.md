# RF와 표면 형상 — 개인 프로젝트 실험 안내

이번 버전의 목표는 **내가 바꾼 입력 → 계산된 변화 → 수치 오차 확인 → 내 해석**을 남기는 것이다.
RF는 회로와 순수 Ar 정상 수지를 연결한다. 표면은 실제 ViennaPS/ViennaLS 엔진으로 움직인다.
두 모듈 사이의 반응 가스·쉬스·플럭스 변환은 아직 검증하지 않았으므로 독립 실험으로 다룬다.

## 바로 시작

형상 실험에는 **목표 설정 → 붉은 주황색 단면 비교 → 항목별 평가 → 진단 그래프**가 추가되었다.
[목표 평가 설명서](NATIVE_TARGET_REVIEW_KR.md)에서 시편 3종, 측정 위치와 수식을 먼저 확인한다.
보고서에는 최종 지표와 함께 당시의 목표 및 판정 버전이 고정된다. 목표가 다른 기록은 같은 기준의 비교로 처리하지 않는다.

1. 저장소 루트에서 `START_RF_LAB.ps1`을 실행하고 [로컬 실험실](http://127.0.0.1:8768/)을 연다. 이미 실행 중이면 바로 접속한다.
2. **RF 매칭 · 플라즈마 → 매칭 ↔ 플라즈마**에서 `RF–플라즈마 함께 계산 · 기록`을 누른다.
3. 수동 C와 재정합의 밀도·벌크 흡수·코일 손실을 함께 읽고 `보고서에 담기`를 누른다.
4. **형상 시뮬레이터**에서 공정을 선택한 뒤 `표면 ripple 예제` 또는 `측벽 scallop 예제`를 연다.
5. 처음/마지막 프레임을 비교하고, 입력 하나를 바꿔 `Run simulation`을 실행한다. 기준 결과는 먼저 `비교 기준으로 고정`한다.
6. `현재 단면 SVG`와 원시 JSON을 저장한다. `보고서에 담기`는 현재 재생 시각과 무관하게 해당 실행의 **최종 결과**를 기록한다.
7. **실험 보고서**에서 제목·사전 가설·해석·추가 측정을 직접 작성하고 Markdown·CSV·JSON으로 내려받는다.

보고서는 브라우저의 로컬 저장소에 최대 50개 실험을 보존한다. 입력은 담는 순간 고정된다.
로컬 서버 주소/포트와 공개 사이트는 서로 다른 저장소다. 다른 컴퓨터로 자동 동기화하지 않으며 JSON은 보관용 내보내기다.
RF/ALD/Etch의 다른 물리를 같은 지표처럼 비교하지 않는다. 같은 모델·버전·초기 형상인 두 항목만 지표 차이를 표시한다.
격자·시드·입자 수는 비교할 수 있으며, 달라진 입력을 별도로 표시한다.

## 1. RF 매칭에 따라 플라즈마가 어떻게 바뀌는가

**기존 회로 · 매칭:** 전자밀도와 충돌 빈도를 사용자가 지정한다.
**새 매칭 ↔ 플라즈마:** 압력·기체 온도·기하를 주고 전자온도와 전자밀도를 계산한다.
기존 화면의 밀도·충돌 빈도·밀도 배수 입력은 결합 모드에서 사용하지 않는다. 쉬스 두께는 여전히 고정 입력이다.

회로는 `exp(+jωt)` RMS 페이저, 50 Ω 기준, SI 단위다. 전력에 1/2를 추가하지 않는다.

```text
ng = p / (kB Tg)                    중성 Ar 밀도 [m^-3]
ng Kiz(Te) V = uB(Te) Aeff          입자 수지
Pbulk(ne, Cp, Cs) = ne e uB Aeff Epair,eV    전력 수지 [W]
Lb = me l / (ne e² A); Rb = nu Lb   밀도가 회로 부하로 되먹임
nu = ng Kel(Te) + mean(ve) / l      충돌 + 유효 transit 항 [s^-1]
Gamma_i = hl ne uB                  전극 벽 가장자리 Ar 이온 플럭스 [m^-2 s^-1]
```

`Kiz, Kex, Kel`은 기존 Ar 학습 모델의 Maxwellian 1–7 eV 속도식을 그대로 사용한다.
원통의 반지름은 RF 면적에서, 길이는 벌크 길이에서 구한다. `Aeff`는 기존 모델의 경험적 벽 가장자리 계수를 사용한다.
전자/이온 벽 손실은 기존 `7.2 Te` 근사, 충돌 손실은 이온화·여기·탄성 항이다.
이 기하·벽 손실 근사가 모든 CCP 장비를 대표하는 것은 아니다.

입자 수지의 Te 해가 1–7 eV 밖이면 계산을 거부한다. 밀도는 `1e12–min(1e20, 0.02 ng) m^-3`에서 탐색한다.
`d(Pbulk−Ploss)/dne < 0`인 해 중 가장 높은 밀도를 선택한다. 이는 단일 수지식의 국소 기울기 기준이며 실제 방전 안정성·점화 증명이 아니다.
허용 해가 없으면 숫자를 0으로 채우지 않고 계산 불가로 표시한다.
재정합은 Cp, Cs, ne를 양수 로그 변수로 동시에 탐색한 뒤 다시 수지 해를 확인한다. C 범위는 10–3000 pF다.

**해석할 때:** 이 단순 모델에서 Te는 압력·기하에 의해 정해진다. 전력이나 C만 바꾸면 Te가 일정하고 ne가 변할 수 있다.
화면의 밝기는 두 해의 평균 밀도 비교다. 발광 강도, 전자 공간 분포, 점화 영상, RF 시간 과도응답을 계산한 것이 아니다.
Ar 플럭스를 SF₆/O₂ 식각 플럭스나 thermal ALD 성장률로 직접 전달하지 않는다.

기본 결합 예제의 실제 계산: 300 W, 13.56 MHz, Q100, Ar 20 mTorr/350 K.

| 지표 | 수동 Cp/Cs=500/120 pF | 결합 재정합 |
|---|---:|---:|
| ne / m^-3 | 2.15335e16 | 4.34939e16 |
| Te / eV | 2.84729 | 2.84729 |
| 벌크 흡수 / W | 9.40372 | 18.99389 |
| 반사 / % | 73.9619 | 수치적으로 약 0 |

재정합해도 300 W가 모두 벌크로 가지 않는다. 고정 쉬스·코일 손실을 포함한 이 예제의 결과이며, 장비에 맞춰 튜닝한 수치가 아니다.
결합 원리 참고: [Schmidt et al., 2018](https://arxiv.org/abs/1804.05638).
해당 논문의 비선형 쉬스·자기 바이어스 계산까지 재현한 구현은 아니다.

## 2. 표면 ripple과 측벽 scallop

두 형상 모두 **초기 조건**으로 넣고 실제 엔진의 수송·피복률·표면 이동으로 후속 변화를 계산한다.
자발적인 ripple 불안정성이나 Bosch의 식각/패시베이션 반복으로 scallop이 생성되는 과정은 구현하지 않았다.
새 형상에는 마스크가 없다. 기존 마스크 식각 예제는 별도 모드로 보존했다.

| 입력 | 평면 ripple | 측벽 scallop |
|---|---|---|
| 진폭 A [nm] | 평균선에서 위/아래 진폭, 초기 PV≈2A | 원래 측벽에서 최대 후퇴량 |
| 반복 수 N | 영역 폭 안의 주기 수 | 초기 홈 깊이 안의 주기 수 |
| 파장 λ [nm] | pitch/N | depth/N |
| 초기 식 | y=A cos(2πNx/pitch) | 왼쪽 x=−width/2−A(1−cos(2πNy/depth))/2; 오른쪽 대칭 |

좌표는 x 수평, y 위쪽 양수, nm 표시/엔진 내부 μm다. 좌우 반사 경계와 정수 주기를 사용한다.
0이 아닌 A는 최소 2격자, λ는 최소 12격자로 제한한다. 이 하한을 만족해도 수렴을 보장하지는 않는다.

**평면 지표:** 256개 등간격 x 중점에서 가장 위의 표면 높이를 구한다.
평균을 뺀 RMS가 Rq, 절대값 평균이 Ra, 최고−최저가 PV다. 평균 식각량은 초기 평균높이−현재 평균높이, 증착량은 반대 부호다.
**측벽 지표:** 초기 깊이의 10–90% 구간에서 161개 고정 y 위치를 표본화한다. 좌우 각각 직선 추세를 제거한 x 잔차의 RMS다.
따라서 벽 기울기와 주기적 요철을 분리하려는 지표이며, 평면 Rq와 정의가 다르다. 표면을 찾지 못하면 해당 지표는 NULL이다.

ALD는 충분한 노출에서 요철을 거의 그대로 따라 덮을 수도 있다. “증착하면 무조건 평탄화”를 전제하지 않는다.
Monte Carlo 잡음과 level-set 격자 오차는 물리적인 원자 거칠기가 아니다.

## 3. 보고서용 최소 실험 — 10개 조건부터

먼저 3개 질문 중 하나를 주제로 삼고, 나머지는 보조 실험으로 쓰면 범위가 관리된다.
예제 선택 후 한 번 로컬 계산해서 자신의 실행 ID를 남긴다. 아래 시간·사이클은 장비 추천 레시피가 아닌 계산 실습 범위다.

| 번호 | 모듈 / 바꿀 조건 | 유지할 조건 / 읽을 지표 |
|---|---|---|
| 1 | RF 결합 Q100 기본 | 수동/재정합 ne, 반사, 벌크·코일 W |
| 2 | Q만 15 | 1과 같은 전력·가스·기하; 정합과 유효 전력 분리 |
| 3 | Q100에서 진행파만 150 W | Te 고정 가정과 ne 응답 확인 |
| 4 | Etch ripple 기본 예제, 0.15 s | A8 nm, N3, grid2 nm, rays300 |
| 5 | 4에서 이온 방향성 지수만 50 | 평균 제거량·Rq·단면 변화 |
| 6 | Etch scallop 기본 예제 | 240 nm 초기 홈, 추가 깊이·좌우 벽 Rq |
| 7 | ALD ripple 기본 예제, 40 cycle | 평균 성장량·Rq; 초기 요철 보존 여부 |
| 8 | ALD scallop 기본 예제 | 상단/바닥 두께·최소 통로·측벽 Rq |
| 9 | 8에서 pulse만 0.002 s | 노출 부족과 피복 비교 |
| 10 | 가장 큰 차이가 난 조건의 seed만 +1 | 차이가 샘플링 변화에서도 유지되는지 확인 |

주요 결론으로 삼을 조건은 grid 4/2 nm 및 rays 300/600도 비교한다. 이 두 수준만으로 수렴을 선언하지 않는다.
동일한 최종 시간/사이클, 초기 형상, 물리 입력을 유지한다. 공정 변수를 여러 개 동시에 바꾸면 각각의 기여를 분리할 수 없다.

보고서 문장 틀:

> 질문: ______. 가설: ______. 고정한 조건: ______. 바꾼 입력: ______.
> 계산에서 관측한 값: ______. 격자·시드 검사 결과: ______.
> 이 모델 안에서 가능한 해석: ______. 다른 원인/미계산 물리: ______.
> 실제 검증에 필요한 측정: ______.

정합은 RF V/I·반사·부품 손실 측정, 밀도는 적절한 플라즈마 진단, 표면은 단면 SEM/AFM 등과 비교할 계획을 설명한다.
현재 측정하지 않은 결과를 경험으로 작성하지 않는다. ViennaTools 엔진 사용, 본인이 설계한 연결/실험/분석, AI 구현 지원을 구분한다.

## 4. 저장과 재현

### 이번 버전의 수치 대조 결과

평면 A8 nm/N3, 같은 물리 입력에서 마지막−초기 Rq를 계산했다. Etch는 0.15 s, ALD는 40 cycle이다.

| 수치 조건 | Etch ΔRq / nm | ALD ΔRq / nm |
|---|---:|---:|
| grid2 / rays300 / seed20261003 | −0.02806 | −0.009460 |
| grid만 4 nm | −0.05445 | −0.015962 |
| seed만 +1 | −0.02683 | −0.009442 |
| rays만 600 | −0.02389 | −0.009560 |

**Observed:** 이 대조에서 평균 제거량은 약 8.813–8.819 nm, ALD 평균 성장량은 약 4.050–4.051 nm였다.
반면 작은 Rq 감소량은 격자 변경에 민감했다. **Inferred:** 평균 진행량에 비해 미세한 평탄화량의 정량적 신뢰도가 낮다.
이를 근거로 물리적 평탄화 성능이나 완전한 격자 수렴을 주장하지 않는다. 측벽 scallop은 이 대조표의 검사 대상이 아니다.

### 산출물 위치

- RF 결합: `outputs/rf_coupled/<run_id>/result.json`; 입력·가스·해·잔차·버전·소스 SHA-256 포함.
- 표면: `outputs/native_lab/<run_id>/`; request/result JSON, VTK/level set, 진행 로그 포함.
- 보고서: 브라우저에서 Markdown, CSV, JSON을 내보내고 단면 SVG와 함께 개인 보고서 폴더에 보관한다.
- Superset: `rf_coupled_cases`와 `surface_results`에서 결합 해·거칠기·격자·seed를 조회한다. 표면 새 계산 뒤 **결과 동기화**를 누르고 대시보드를 새로 고친다.
- 수치 대조: `python -m native_lab.check_profile_sensitivity`; [원시 요약](validation/profile_sensitivity.json). 평면 ripple만 검사한 제한된 수치 민감도 자료다.

참고 엔진: [ViennaPS 4.6.2](https://github.com/ViennaTools/ViennaPS/tree/v4.6.2), [ALD 모델 논문](https://arxiv.org/abs/2210.00749).
실제 장비 보정, 자발적 요철 형성, 3D 반응기 해석, RF→반응성 플라즈마→표면의 통합 검증은 남아 있다.
