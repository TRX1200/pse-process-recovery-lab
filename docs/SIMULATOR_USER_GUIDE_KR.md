# ALD / Etch Lab 사용 설명서

공정 입력을 이해하고, 표면 변화와 계산 결과를 읽는 안내서.

## 이 도구가 계산하는 것

현재 도구는 공정 조건 → 축약 물리 모델 → 두께·제거량·시간 응답을 연결하는 학습용 시뮬레이터입니다. 실제 장비나 재료에 맞춰 보정한 레시피 설계 도구는 아닙니다.

ALD는 고정된 1D 평행 평판 채널에서 분압·반응·확산을 첫 사이클 동안 계산합니다. Etch는 정상 0D Ar 플라즈마와 가상 반응종의 표면 제거를 계산하고, 가정한 방사형 이온 플럭스를 적용합니다.

2D/3D 패턴 형상 해석과 비교하면, 현재 도구에는 움직이는 경계 계산이 없습니다. 트렌치 측벽·언더컷·재증착·패턴 CD를 풀지 않으며, ALD에서도 막 성장으로 좁아진 채널을 다음 계산에 반영하지 않습니다. 패턴 형상 변화가 목표인 실험에는 별도의 형상 진화 모델이 필요합니다.

## 처음 10분: 한 조건만 바꾸기

1. 공정 선택 후 표면 관찰 탭을 엽니다. 기본 조건으로 계산하고, 처음으로 → 재생 → 일시정지로 시간별 단면을 확인하세요.

2. 핵심 조건 하나만 바꿔 다시 계산합니다. Etch는 처리 시간 60→90 s, ALD는 A 주입 0.5→1 s부터 시도하세요. 나머지 값과 이상 조건은 유지합니다. 결과 방향은 직접 확인하고 기록합니다.

3. 단면의 실제 nm 값과 아래 시간 그래프를 함께 봅니다. 입력을 수정하기만 하면 화면 결과는 이전 실행입니다. 다시 계산해야 반영됩니다.

4. 실험 노트 탭에서 정상·이상·조치 비교를 실행합니다. 계산 전 가설과 내 해석을 쓰고 JSON·Markdown 보고서를 저장하세요. 표면 그림 하나만으로 원인을 확정하지 않습니다.

## 입력은 세 층으로 나누기

핵심 조건: 처음에는 Etch의 소스 전력·압력·바이어스·처리 시간, ALD의 A 주입·A 뒤 퍼지·B 주입·B 뒤 퍼지 4개만 사용합니다.

나머지 레시피·챔버 조건: 유량·분압·온도·형상·공급 및 배기 응답입니다. 원인 가설이 생겼을 때 하나씩 확장하세요. 온도와 밀도, 길이와 간격의 단위를 먼저 읽습니다.

고급 모델 계수: 반응 확률·반응 자리 밀도·제거 수율·문턱 에너지 등입니다. 실제 장비의 조작 버튼과 다릅니다. 처음에는 기본값을 유지하고, 바꿀 때는 근거와 민감도 실험임을 기록하세요.

입력 범위는 소프트웨어가 허용하는 값입니다. 실제 공정의 안전 범위나 보정된 모델 유효 범위를 뜻하지 않습니다. 정상 조건에서는 이상 강도가 0.35여도 고장 효과를 적용하지 않습니다.

## ALD 단면과 지표 읽기

초록 막은 첫 사이클의 누적 성장량입니다. A 주입 때 표면 피복률이 변해도 아직 성장량이 작거나 0일 수 있습니다. A 피복률과 막 두께는 같은 값이 아닙니다.

단면은 기본 100배 막 두께 표시를 사용하며 큰 성장에서는 배율을 낮춥니다. 축척과 실제 nm 값을 읽으세요. 계단은 셀별 표시이며 실제 거칠기를 예측한 결과가 아닙니다.

반복 횟수 N은 첫 사이클 종점 두께에 곱합니다. 총 투영 두께와 첫 사이클 단면 값을 혼동하지 마세요. 입구/깊은 곳 값은 정확한 경계가 아닌 첫/마지막 셀 중심값입니다.

두께가 목표와 가까운지, 깊은 곳/입구 쪽 두께비가 충분한지, A/B 중첩·종료 잔류·사이클 시간이 함께 괜찮은지 봅니다. 중첩은 모델 지표이며 실제 불순물 농도나 결함률은 아닙니다.

## Etch 단면과 지표 읽기

붉은 부분은 제거된 재료, 회색은 남은 재료입니다. 가로 mm와 세로 nm의 축척이 다릅니다. 거의 평평하면 위치별 차이가 작은 것이며, 패턴 형상이 숨어 있는 화면이 아닙니다.

시간 그래프의 타깃 제거량은 균일 대표 플럭스 기준이고, 결과 표의 식각 깊이는 면적 평균입니다. 단면 중앙의 국소 깊이와도 구분합니다.

소스 전력은 흡수 전력과 전자밀도에, 바이어스는 평균 이온 에너지 근사에 연결됩니다. 깊이만 좋아져도 마스크 손실·선택비·균일도가 나빠질 수 있으므로 함께 평가하세요.

공정 평가의 충족/미달은 설정한 예제 규격의 판정입니다. CD·측벽 각도·손상·잔류물처럼 계산하지 않은 항목까지 합격했다는 뜻이 아닙니다.

## 정상·이상·조치 실험과 저장

Etch 실험 노트는 기준 → RF 반사 증가 → 같은 손실 아래 소스 전력 보상을 비교합니다. 모델에서 깊이가 돌아와도 RF 매칭 장치가 수리됐다는 증거가 아닙니다.

ALD 실험 노트는 기준 → 배기 응답 지연 → 퍼지 연장을 비교합니다. 잔류가 줄어드는 이점과 늘어난 처리 시간, 남아 있는 두께비 미달을 함께 적습니다.

표면 관찰에서 SVG를 저장하면 현재 시간·프로파일·조건 메타데이터가 포함됩니다. SVG 저장은 Chrome에서 확인했습니다. 전체 재현에는 레시피 JSON 또는 실행 JSON과 모델 버전도 보관하세요. MP4 내보내기는 현재 없습니다.

실행 기록에는 최근 10개가 브라우저에 보관됩니다. 저장 공간 삭제에 대비해 파일을 내려받으세요. 지원 자료에는 사용한 가정, 직접 바꾼 조건, 관측한 지표, 아직 모르는 점을 함께 남깁니다.

## 화면이 예상과 다를 때

파라미터를 바꿨는데 단면이 그대로: 변경 대기 표시를 확인하고 다시 계산합니다. N만 바꾼 ALD 첫 사이클 영상은 같을 수 있습니다.

공정이나 탭을 바꿨더니 멈춤: 화면에서 벗어나거나 브라우저가 숨겨지면 재생을 멈춥니다. 다시 재생 버튼을 누르세요.

Etch가 0 또는 평가 불가: 소스 전력·듀티·반사율·결합 효율과 모델 진단을 확인합니다. 속도식 적용 범위 밖 결과를 정상 예측으로 해석하지 마세요.

첫 계산이 늦음: 공개 사이트는 Python·NumPy·SciPy를 브라우저로 불러옵니다. 엔진 준비 표시를 확인하세요. 계산 오류가 나면 입력 범위와 오류 문구부터 확인합니다.

## Plasma Etch 전체 파라미터 (31개)

모델 버전: etch-ar-global-0.1.1

### 소스 전력 (source_power_w)

분류: 먼저 조절 · 단위: W · 기본값: 600 · 입력 범위: 0–3000

발진기 전력. 반사·결합·듀티를 거쳐 흡수 전력을 계산합니다.

전자계에 공급되는 흡수 전력을 바꿉니다. 전자밀도·식각 깊이·마스크 손실을 함께 보세요. 이 모델에서 고정 압력·형상의 전자온도는 전력만으로 증가하지 않습니다.

### 압력 설정 (pressure_mtorr)

분류: 먼저 조절 · 단위: mTorr · 기본값: 20 · 입력 범위: 1–150

정압 제어 가정. 압력 고장은 실제 압력에 적용됩니다.

기체 밀도, 입자 수지, 이온 충돌 감쇠에 함께 작용합니다. 깊이가 항상 한 방향으로 바뀐다고 가정하지 말고 이온 에너지·밀도도 확인하세요.

### 총 유량 (flow_sccm)

분류: 추가 레시피 · 단위: sccm · 기본값: 100 · 입력 범위: 1–500

273.15 K, 1 atm 기준. 체류 시간과 반응 가스 공급량을 바꿉니다.

압력 제어를 유지한 상태에서 체류 시간과 반응종 공급을 바꿉니다. 유량 증가를 압력 증가와 같게 해석하지 마세요.

### 반응 가스 몰분율 (reactive_fraction)

분류: 추가 레시피 · 단위: fraction · 기본값: 0.04 · 입력 범위: 0–0.2

Ar 내 가상 X2 첨가. 실제 SF6/CF4 반응망이 아니며 0.05 초과는 희석 가정에 주의합니다.

Ar 중 가상 X2의 분율입니다. 라디칼 플럭스·피복률·선택비를 보세요. 특정 SF6/CF4 조성의 재현이 아니며 0.05 초과 시 모델 진단을 확인합니다.

### 바이어스 크기 (bias_voltage_v)

분류: 먼저 조절 · 단위: V · 기본값: 120 · 입력 범위: 0–500

웨이퍼의 음의 DC 바이어스 절댓값. RF 파형·IEDF는 풀지 않습니다.

음의 DC 바이어스 절댓값으로 평균 이온 에너지 근사에 작용합니다. 깊이뿐 아니라 마스크 손실·선택비를 확인하세요. 실제 RF 전압 파형은 아닙니다.

### 처리 시간 (process_time_s)

분류: 먼저 조절 · 단위: s · 기본값: 60 · 입력 범위: 0–600

정상 플라즈마에 초기 피복률 0인 표면을 노출하는 시간입니다.

표면을 처리하는 실제 모델 시간입니다. 초기 표면 반응 이후 제거량이 어떻게 쌓이는지 보세요. 전원을 켜서 플라즈마가 점화되는 시간은 아닙니다.

### 소스 듀티 (source_duty)

분류: 추가 레시피 · 단위: fraction · 기본값: 1 · 입력 범위: 0–1

평균 흡수 전력 근사이며 펄스별 켜짐·꺼짐 응답은 계산하지 않습니다.

평균 흡수 전력에 곱하는 비율입니다. 0이면 소스 전력이 꺼집니다. 펄스 주파수나 잔광 물리를 평가하는 입력은 아닙니다.

### 고장 강도 (fault_severity)

분류: 이상 주입 · 단위: fraction · 기본값: 0.35 · 입력 범위: 0–1

선택한 고장의 상류 물리 조건 변화량입니다. 0은 정상과 같습니다.

현재 선택한 고장의 정도입니다. 정상 조건에서는 작용하지 않습니다. RF 손실·압력·가스·벽 상태 중 하나를 선택해 사용합니다.

### RF 반사 전력 비율 (reflected_fraction)

분류: 챔버·형상 · 단위: fraction · 기본값: 0.04 · 입력 범위: 0–1

반사 전력/순방향 전력. 1이면 소스 흡수 전력이 0입니다.

반사 전력/순방향 전력 비율입니다. 높이면 전달 가능한 전력이 줄어듭니다. RF 매칭 이탈 고장도 이 비율을 추가로 높입니다.

### 전력 결합 효율 (coupling_efficiency)

분류: 챔버·형상 · 단위: fraction · 기본값: 0.75 · 입력 범위: 0–1

전달된 소스 전력 중 전자계 흡수 비율. 임피던스는 계산하지 않습니다.

반사를 제외한 전달 전력 중 전자계에 흡수되는 비율입니다. 측정값 없이 조정하면 결합 효율에 대한 가정 탐구입니다.

### 기체 온도 (gas_temperature_k)

분류: 챔버·형상 · 단위: K · 기본값: 350 · 입력 범위: 250–800

중성 기체 온도 입력. 열전달 방정식으로 예측하지 않습니다.

중성 기체 온도입니다. °C가 아니라 K입니다. 중성 밀도·열운동 등에 쓰며 챔버 열해석의 출력이 아닙니다.

### 챔버 반경 (radius_mm)

분류: 챔버·형상 · 단위: mm · 기본값: 180 · 입력 범위: 80–300

원통형 플라즈마 유효 반경입니다.

유효 플라즈마 부피와 벽 손실 면적에 작용합니다. 웨이퍼 표시 반경도 연결되어 있습니다. 장비 형상 가정이므로 레시피 실험에서는 고정하세요.

### 플라즈마 높이 (height_mm)

분류: 챔버·형상 · 단위: mm · 기본값: 100 · 입력 범위: 30–300

원통형 플라즈마 유효 높이입니다.

유효 플라즈마 높이입니다. 부피·벽 손실을 바꾸는 형상 가정입니다. 쉬스 두께 관련 진단도 확인하세요.

### 벽 라디칼 손실 확률 (wall_recombination)

분류: 챔버·형상 · 단위: fraction · 기본값: 0.05 · 입력 범위: 0.001–1

벽에서 X가 제거될 확률. 재결합 생성물은 반응망에 재주입하지 않습니다.

벽에서 라디칼이 사라지는 확률입니다. 라디칼 플럭스와 표면 응답을 비교하세요. 실제 벽의 세정 상태와 일대일 대응하는 측정값은 아닙니다.

### 가정한 이온 플럭스 편차 (radial_nonuniformity)

분류: 챔버·형상 · 단위: fraction · 기본값: 0.12 · 입력 범위: 0–0.5

면적 평균이 1인 포물선 이온 플럭스 분포의 계수. 공간 PDE 결과가 아닙니다.

웨이퍼 위치별 이온 플럭스에 부여하는 분포 계수입니다. 0에서는 평탄한 입력 분포를 사용합니다. 전자기장 해석에서 얻은 균일도가 아닙니다.

### 이온-중성 충돌 단면적 (ion_cross_section_1e19_m2)

분류: 모델 계수 · 단위: 10^-19 m² · 기본값: 10 · 입력 범위: 1–30

일정한 유효 Ar 충돌 단면적 가정. 실제 에너지 의존 단면적이 아닙니다.

쉬스 내 이온 충돌 감쇠에 쓰는 단면적 가정입니다. 입력 10은 10×10⁻¹⁹ m²입니다. 이온 에너지 변화를 확인합니다.

### 가상 라디칼 질량 (radical_mass_amu)

분류: 모델 계수 · 단위: u · 기본값: 19 · 입력 범위: 1–100

열운동 플럭스를 계산하는 X의 질량. 19는 F와 유사한 질량일 뿐 F 화학 모델은 아닙니다.

가상 X의 열운동 플럭스 계산에 쓰는 질량입니다. 19로 설정해도 불소 화학 전체가 구현되는 것은 아닙니다.

### 해리 계수 전인자 (dissociation_prefactor_1e14_m3_s)

분류: 모델 계수 · 단위: 10^-14 m³/s · 기본값: 2 · 입력 범위: 0.01–10

가상 X2의 k_d = A exp(-E_d/Te). 문헌 보정 전인 조정 계수입니다.

가상 X2 해리 속도식의 크기를 정합니다. 입력 값에 10⁻¹⁴ m³/s를 곱합니다. 재료 반응 모델의 가정입니다.

### 해리 에너지 계수 (dissociation_threshold_ev)

분류: 모델 계수 · 단위: eV · 기본값: 5 · 입력 범위: 1–15

가상 반응의 속도 계수와 에너지 손실에 쓰는 가정값입니다.

가상 해리 속도와 에너지 손실의 계수입니다. 전자 에너지 수지·라디칼 공급이 함께 달라질 수 있습니다.

### 표면 반응 흡착 확률 (sticking_probability)

분류: 모델 계수 · 단위: fraction · 기본값: 0.15 · 입력 범위: 0–1

X가 비어 있는 표면 반응 자리에 흡착할 확률입니다.

비어 있는 표면에 X가 흡착할 확률입니다. 피복률과 반응 제거 경로를 함께 바꿉니다.

### 표면 자리 밀도 (surface_site_density_1e18_m2)

분류: 모델 계수 · 단위: 10^18 m^-2 · 기본값: 7 · 입력 범위: 1–20

표면 피복률 방정식의 단위 면적당 반응 자리 수입니다.

피복률 환산에 쓰는 반응 자리 밀도입니다. 입력 7은 7×10¹⁸ m⁻²입니다. 재료별 근거 없이 레시피 노브처럼 조절하지 않습니다.

### 열적 탈착 계수 (thermal_desorption_s)

분류: 모델 계수 · 단위: s^-1 · 기본값: 0.1 · 입력 범위: 0–20

기판 온도 의존성을 대신하는 입력 계수. 온도 예측은 없습니다.

흡착종이 표면에서 탈착하는 속도 계수입니다. 기판 온도 예측을 대신하는 입력 가정이며 피복률에 작용합니다.

### 자발적 표면 제거 계수 (chemical_rate_s)

분류: 모델 계수 · 단위: s^-1 · 기본값: 2 · 입력 범위: 0–20

피복된 자리의 자발적 제거 속도. 특정 재료의 측정값이 아닙니다.

피복된 표면의 자발적 제거 속도입니다. 제거와 피복률 소모가 결합되어 있어 깊이만으로 해석하지 않습니다.

### 이온 보조 제거 계수 (etch_yield_scale)

분류: 모델 계수 · 단위: atoms/ion · 기본값: 1.5 · 입력 범위: 0–5

Y = 계수 × max(sqrt(E/Eth)-1,0). 일반화한 교육용 반응 수율입니다.

이온 보조 반응 수율의 크기입니다. 두께를 맞추기 위해 바꾸면 모델 보정이며 공정 레시피 개선과 구분해야 합니다.

### 이온 보조 문턱 (etch_threshold_ev)

분류: 모델 계수 · 단위: eV · 기본값: 20 · 입력 범위: 1–100

가정한 이온 보조 반응 문턱 에너지입니다.

이온 보조 반응이 시작되는 문턱 가정입니다. 현재 평균 이온 에너지와 비교해 해당 경로가 켜지는지 확인하세요.

### 타깃 스퍼터 계수 (sputter_yield_scale)

분류: 모델 계수 · 단위: atoms/ion · 기본값: 0.15 · 입력 범위: 0–1

피복되지 않은 표면에도 작동하는 일반화한 물리 제거 계수입니다.

타깃의 물리적 스퍼터 제거 계수입니다. 화학 반응 경로와 구분해서 봅니다.

### 타깃 스퍼터 문턱 (sputter_threshold_ev)

분류: 모델 계수 · 단위: eV · 기본값: 60 · 입력 범위: 1–300

타깃의 가정한 물리적 제거 문턱입니다.

타깃 스퍼터 문턱 에너지입니다. 그 이하에서는 이 모델의 해당 수율이 0입니다.

### 마스크 스퍼터 계수 (mask_yield_scale)

분류: 모델 계수 · 단위: atoms/ion · 기본값: 0.05 · 입력 범위: 0–1

마스크의 일반화한 물리 제거 계수입니다.

마스크의 물리적 제거 계수입니다. 마스크 손실과 선택비의 분모에 작용합니다.

### 마스크 스퍼터 문턱 (mask_threshold_ev)

분류: 모델 계수 · 단위: eV · 기본값: 40 · 입력 범위: 1–300

가정한 마스크 제거 문턱입니다.

마스크 스퍼터 문턱입니다. 마스크 제거율이 0이면 선택비는 무한대의 성공값이 아니라 정의 불가입니다.

### 타깃 원자 밀도 (target_density_1e28_m3)

분류: 모델 계수 · 단위: 10^28 m^-3 · 기본값: 5 · 입력 범위: 1–10

제거 원자 플럭스를 두께로 변환합니다. 기본값은 Si와 비슷한 크기의 가정값입니다.

제거된 원자 수를 타깃 두께로 바꾸는 밀도입니다. 다른 제거 조건이 같을 때 높은 밀도는 더 작은 nm 제거량으로 환산됩니다.

### 마스크 원자 밀도 (mask_density_1e28_m3)

분류: 모델 계수 · 단위: 10^28 m^-3 · 기본값: 5 · 입력 범위: 1–10

마스크 제거량의 두께 환산에 쓰는 가정값입니다.

마스크 원자 제거량을 nm 손실로 환산합니다. 타깃 밀도와 별개의 재료 가정입니다.

### 이상 모드

- 정상 조건: 레시피와 장비 설정값을 그대로 적용합니다.
- RF 매칭 이탈: 반사율을 r + (1-r)×강도로 높여 흡수 전력을 감소시킵니다.
- 압력 제어 편차: 실제 압력을 설정값×(1+강도)로 바꿉니다.
- 반응 가스 공급 저하: 반응 가스 유량을 (1-강도)배로 줄입니다. Ar 유량과 압력 제어는 유지합니다.
- 벽 상태 변화: 벽 라디칼 손실 확률을 γ + (1-γ)×강도로 높입니다.

## ALD 전체 파라미터 (17개)

모델 버전: ald-reactive-diffusion-1.0.1

### A 주입 (pulse_a_s)

분류: 먼저 조절 · 단위: s · 기본값: 0.5 · 입력 범위: 0–5

전구체 A 밸브 개방 시간

A가 공급되는 시간을 바꿉니다. 입구·깊은 곳 A 피복률을 비교하고, 시간을 더 늘려도 응답 변화가 작아지는지 확인하세요.

### A 뒤 퍼지 (purge_a_s)

분류: 먼저 조절 · 단위: s · 기본값: 1.5 · 입력 범위: 0–8

A 공급 차단 후 배기 시간

A 공급을 끊고 배기하는 시간입니다. B 주입 직전 A 잔류와 A/B 중첩을 관찰하세요. 길게 하면 사이클 시간도 늘어납니다.

### B 주입 (pulse_b_s)

분류: 먼저 조절 · 단위: s · 기본값: 0.5 · 입력 범위: 0–5

반응물 B 밸브 개방 시간

A 종결 표면을 B가 전환하며 막이 자라는 구간입니다. 누적 성장과 깊이별 두께를 보세요. 충분한 공급 이후에는 증가 폭이 작아질 수 있습니다.

### B 뒤 퍼지 (purge_b_s)

분류: 먼저 조절 · 단위: s · 기본값: 1.5 · 입력 범위: 0–8

B 공급 차단 후 배기 시간

B 공급 차단 후 배기 시간입니다. 종료 잔류와 사이클 시간을 비교하세요. 이 모델의 다음 사이클은 별도로 적분하지 않습니다.

### A 목표 분압 (pressure_a_pa)

분류: 추가 레시피 · 단위: Pa · 기본값: 20 · 입력 범위: 0–200

주입 시 챔버 A 분압의 목표값; 총압과 다름

A의 공급 세기를 바꿉니다. 총압과 구분하세요. 주입 시간은 고정하고 A 피복률·깊이별 성장을 비교합니다.

### B 목표 분압 (pressure_b_pa)

분류: 추가 레시피 · 단위: Pa · 기본값: 30 · 입력 범위: 0–200

주입 시 챔버 B 분압의 목표값

B 공급 세기입니다. B 반응에 의한 성장과 잔류를 함께 보세요. 압력과 주입 시간을 동시에 바꾸지 말고 원인을 나눠 확인합니다.

### 공정 온도 (temperature_c)

분류: 추가 레시피 · 단위: °C · 기본값: 200 · 입력 범위: 100–350

균일 온도 가정; 실제 재료의 ALD window를 보증하지 않음

확산과 유효 반응 확률에 함께 작용합니다. 실제 ALD 공정창을 찾는 입력으로 해석하지 마세요. 이 모델에는 응축·열분해가 없습니다.

### 반복 횟수 (cycles)

분류: 추가 레시피 · 단위: cycle · 기본값: 50 · 입력 범위: 1–150

대표 한 사이클 결과의 선형 투영; 다중 사이클 독립 계산 아님

첫 사이클 성장량에 곱하는 횟수입니다. 50→100이면 투영 두께는 두 배가 되지만 표면 재생 영상은 여전히 첫 사이클입니다.

### 채널 깊이 (depth_um)

분류: 챔버·형상 · 단위: µm · 기본값: 40 · 입력 범위: 1–200

입구 x=0, 막힌 끝 x=L인 평행 평판 채널

입구에서 막힌 끝까지 거리입니다. 간격을 고정하고 깊은 곳 공급·성장 차이를 관찰하세요. 실제 패턴의 3D 형상 입력은 아닙니다.

### 채널 간격 (gap_um)

분류: 챔버·형상 · 단위: µm · 기본값: 0.2 · 입력 범위: 0.05–2

두 반응 벽 사이 초기 간격; 계산 중 고정

평행한 두 벽 사이 초기 간격입니다. 깊이/간격 비와 수송 조건이 변합니다. 성장한 막 때문에 간격이 줄어드는 피드백은 없습니다.

### 챔버 응답 시간 (residence_time_s)

분류: 챔버·형상 · 단위: s · 기본값: 0.15 · 입력 범위: 0.02–2

집중정수 분압 상승·배기 시정수

분압이 목표값으로 오르거나 배기되는 속도의 시정수입니다. 크면 응답이 느려집니다. 배기 지연 고장은 배기 구간 시정수에 별도로 작용합니다.

### A 유효 부착 확률 (sticking_a)

분류: 모델 계수 · 단위: 무차원 · 기본값: 0.001 · 입력 범위: 0.00001–0.01

200 °C 기준 가정값; 표면 화학을 묶은 유효 계수

A 흡착의 유효 확률입니다. 높이면 입구 소비와 안쪽 공급이 함께 달라질 수 있습니다. 재료 특성 가정이므로 처음에는 고정합니다.

### B 유효 반응 확률 (sticking_b)

분류: 모델 계수 · 단위: 무차원 · 기본값: 0.0005 · 입력 범위: 0.00001–0.01

200 °C 기준 가정값; A 종결 표면에 반응

B가 A 종결 표면에 반응할 유효 확률입니다. 성장 속도와 수송의 경쟁을 바꿉니다. 장비의 직접 조절 노브가 아닙니다.

### 표면 자리 밀도 (site_density_nm2)

분류: 모델 계수 · 단위: nm⁻² · 기본값: 5 · 입력 범위: 1–10

기체 소모와 피복률을 연결하는 유효 반응 자리 밀도

단위 면적당 반응 가능한 자리 수입니다. 기체 소모와 피복률 환산을 함께 바꾸는 재료 가정입니다.

### 포화 성장 환산량 (gpc_saturated_nm)

분류: 모델 계수 · 단위: nm/cycle · 기본값: 0.1 · 입력 범위: 0.02–0.2

표면 1회 A→B 전환당 두께 환산값; 특정 재료 실측값 아님

A→B 전환 횟수를 nm로 바꾸는 두께 환산 계수입니다. 크게 해서 두께를 맞추는 일은 레시피 개선이 아니라 모델 계수 조정입니다.

### 유효 활성화 에너지 (activation_ev)

분류: 모델 계수 · 단위: eV · 기본값: 0.12 · 입력 범위: 0–0.3

가정된 Arrhenius 온도 의존성; 탈착·열분해 미포함

온도 변화에 대한 반응 확률의 민감도 가정입니다. 공정 온도를 고정하고 계수 민감도를 볼 때 사용합니다.

### 이상 강도 (fault_severity)

분류: 이상 주입 · 단위: 무차원 · 기본값: 0.35 · 입력 범위: 0–1

선택한 이상 모드가 상류 공급·배기·온도에 작용하는 정도

선택한 이상 모드의 정도입니다. 이상을 정상으로 두면 작용하지 않습니다. 다른 조건을 고정하고 0과 0.35를 비교해 보세요.

### 이상 모드

- 정상: 설정값 그대로 계산
- 전구체 공급 저하: A의 실제 목표 분압을 (1−강도)배로 감소
- 배기 응답 지연: 밸브 차단 후 배기 시정수를 (1+8×강도)배로 증가
- 히터 온도 하락: 실제 온도가 설정값보다 최대 60 °C 낮아짐
