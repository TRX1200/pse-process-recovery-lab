# Al₂O₃ ALD: 직접 비교하는 10개 실험

이 문서는 **실험 계획**이다. 아래 값은 학습용 모델의 제안 입력이며 장비 레시피나 계산 결과가 아니다.
사이트의 `물리 연속공정 → 증착 실험 10`에서 번호를 누르고 `이 조건 적용`을 선택한다.
로컬 Python 서버에서 `연속 공정 계산`을 눌러야 해당 조건의 결과가 생성된다.
GitHub Pages에서도 조건을 읽고 입력 JSON과 실험표 CSV를 받을 수 있다.

## 1. 어떤 조합인가

각 실험은 Si 식각 → 이상적 마스크 제거 → Al₂O₃ ALD를 계산한다.
P는 **TMA 입구 분압**이고 챔버 총압이 아니다. t는 한 사이클의 TMA 노출 시간이며
퍼지를 포함한 전체 사이클 시간이 아니다. 아래 기대는 검증할 가설이다.

| 번호 | 실험 | P (Pa) | t (s) | 요청 사이클 | 초기 개구 (nm) | 비교 대상 / 질문 |
|---|---|---:|---:|---:|---:|---|
| D01 | 기준 | 3 | 0.02 | 160 | 100 | 기준 두께와 통로 폭은? |
| D02 | 짧은 노출 | 3 | 0.005 | 160 | 100 | D01: 공급 부족으로 성장·두께비가 달라지나? |
| D03 | 긴 노출 | 3 | 0.1 | 160 | 100 | D01: 5배 노출에 성장도 5배인가, 포화하나? |
| D04 | 낮은 분압 | 1 | 0.02 | 160 | 100 | D01: 공급 감소의 영향은? |
| D05 | 높은 분압 | 6 | 0.02 | 160 | 100 | D01: 바닥 성장도 개선되나? |
| D06 | 얇은 막 | 3 | 0.02 | 80 | 100 | D01: 절반 사이클에서 두께도 절반인가? |
| D07 | 두꺼운 막 | 3 | 0.02 | 320 | 100 | D01: 통로 축소가 바닥 수송을 제한하나? |
| D08 | 명목 노출량 일치 | 6 | 0.01 | 160 | 100 | D01: 같은 P×t = 0.06 Pa·s면 같은 결과인가? |
| D09 | 좁은 개구 | 3 | 0.02 | 160 | 60 | D01: 식각 형상과 후속 증착이 어떻게 달라지나? |
| D10 | 좁은 개구 + 긴 노출 | 3 | 0.1 | 160 | 60 | D09: 바닥 성장 개선과 통로 축소의 상충은? |

D08은 두 변수를 동시에 바꾸되 P×t를 유지한 비교다. 나머지 비교는 표의 비교 대상에서
한 입력만 변경한다. D09는 ALD만의 구조 민감도 실험이 아니라 **개구 변경이 식각과 후속
증착에 함께 미치는 영향**이다. 동일 깊이나 동일 종횡비라고 가정하지 않는다.
D10은 D09와 같은 전처리 조건이며 TMA 노출 시간만 늘린다.

공통 고정값: 식각 5 s, 영역 폭 400 nm, 마스크 80 nm, 이온 방향성 지수 500,
이온/F/O 플럭스 12/1800/100 × 10¹⁵ cm⁻² s⁻¹, 평균 이온 에너지 100 eV,
에너지 표준편차 10 eV. ALD 온도 300 °C, 부착 확률 0.0075,
탈착 플럭스 3 × 10¹⁹ m⁻² s⁻¹, 반응 자리 밀도 5 nm⁻², 포화 GPC 0.112 nm/cycle.
수치 조건: 격자 5 nm, 표면점당 300 rays, seed 20261003, 식각 저장 구간 12,
성장 최대 묶음 20 cycles, 피복률 최대 시간 간격 0.001 s.
엔진은 실제 성장 묶음과 시간 간격을 안정성 조건에 따라 더 작게 제한한다.
전체 조건의 기준은 각 실험의 `입력 JSON`이다.

기존 저장 예제 `기준 공정`은 노출 시간이 **0.05 s**다. 이번 D01의 **0.02 s**와 다르다.
D01을 계산하지 않고 기존 저장 예제를 D01의 결과로 사용하면 안 된다.

## 2. 추천 순서와 기록

1. D01을 적용하고 계산한다. 완료 후 `현재 결과 비교 고정`을 누르고 JSON을 저장한다.
2. 먼저 D02 → D03으로 노출 부족/포화를 비교한다. 단면뿐 아니라 진단 그래프의 두께 이력을 본다.
3. D04 → D05 → D08로 공급량과 명목 노출량의 관계를 확인한다.
4. D06 → D07로 두께 증가와 통로 축소를 함께 확인한다.
5. D09를 계산해 결과를 새로 비교 고정한다. D10을 실행해 좁은 구조에서의 조치를 비교한다.
6. 주요 결론은 아래 수치 민감도 점검을 거친 뒤 작성한다.

조건 적용은 모든 입력을 그 실험 값으로 교체한다. 이전에 수동으로 바꾼 식각 조건이나
시드는 남지 않는다. 기존 완료 결과는 유지되며, 새 입력으로 계산하기 전에는 안내가 표시된다.
계산 결과 JSON의 `request.params`와 `run_hash`로 입력과 결과를 연결한다.

| 기록 항목 | 정의 / 해석 |
|---|---|
| 요청 / 완료 사이클 | 요청 N과 마지막 ALD 프레임 `at`를 각각 기록. 조기 종료를 구분한다. |
| 상단 두께 | x = 0.4 × 영역 폭에서 Si 경계와 막 경계의 수직 차이 |
| 바닥 두께 | x = 0에서 두 경계의 수직 차이 |
| 바닥/상단 비 | 두께비 × 100%. 막이 없으면 정의하지 않는다. |
| 겉보기 GPC | 상단 두께 ÷ **완료** 사이클. 입력 포화 GPC와 구별한다. |
| 중간 / 최소 통로 폭 | 지정된 깊이 절단선에서 측정. 최소값은 유한한 샘플 위치 기준이다. |
| 식각 깊이 / 폭 | ALD 전 Strip 형상을 확인. 특히 D09에서 필수다. |
| 해상도 / 표본 수 / seed | 모든 비교 결과에 함께 기록한다. |

높은 두께비 하나로 합격을 판단하지 않는다. 얇아도 두께비는 높을 수 있다.
목표 막 두께, 허용 두께비, 남겨야 할 통로 폭을 먼저 정하고 세 조건을 함께 비교한다.
통로 폭이 2격자보다 작아 계산이 멈추면 이를 실제 폐쇄 시간이나 완전 충진의 증거로 해석하지 않는다.

복사해서 쓸 기록 형식:

```text
실험 ID / 비교 대상:
입력에서 바꾼 값과 가설:
run_hash / 엔진 버전 / grid / rays / seed:
요청 사이클 / 완료 사이클:
상단 두께 / 바닥 두께 / 바닥·상단 비:
중간 통로 / 샘플 최소 통로:
관찰한 차이:
가설을 지지하는가 / 다른 설명은 무엇인가:
수치 민감도 확인 여부 / 아직 말할 수 없는 것:
```

## 3. 왜 온도·퍼지·다른 재료를 섞지 않았나

현재는 TMA 제한 반응과 입자 수송, 피복률에 따른 성장 모델이다. 반대 반응과 퍼지는
완결된다고 가정한다. 온도는 기체 열 플럭스 계산에 들어가지만 반응 계수의 온도 의존성이나
분해·응축을 보정하지 않았으므로 온도를 훑어 실제 ALD window를 얻었다고 할 수 없다.
따라서 이번에는 온도와 화학 계수를 고정하고 제어 가능한 공급·시간·형상을 비교한다.
HfO₂, TiN 등 다른 재료 레시피는 포함하지 않는다.

P×t가 같아도 유한 노출 동안의 탈착과 형상에 따른 수송이 있으므로 같은 성장량을
미리 보장하지 않는다. D08은 이를 확인하는 실험이며 같은 결과가 나와도 실패가 아니다.
노출과 피복의 관계는 [Aguinsky et al. (2022)](https://arxiv.org/abs/2210.00749)와
[ViennaPS 4.6.2 SingleParticleALD 구현](https://github.com/ViennaTools/ViennaPS/blob/v4.6.2/include/viennaps/models/psSingleParticleALD.hpp)을 참고했다.
논문의 실험 보정을 이 프로젝트가 재현했다는 뜻은 아니다.

## 4. 결론을 쓰기 전에

5 nm 격자와 300 rays는 탐색 시작점이다. 특히 D02/D06의 얇은 막이나 좁은 잔여 통로는
정량 해석에 부족할 수 있다. 핵심 비교 쌍 모두에 대해 격자 5 → 2.5 nm,
표본 수 300 → 1000을 **각각 별도 변경**해 효과 크기가 유지되는지 점검한다.
시드도 20261003/20261004/20261005 등으로 바꿔 표본 변동과 구별한다.
단 두 격자 간격의 일치만으로 수렴을 증명했다고 표현하지 않는다.
계산된 미세 요철을 실제 표면 거칠기나 공정 결함으로 바로 해석하지 않는다.

## 5. 입력 파일 재생성

```powershell
.\.venv\Scripts\python.exe -m native_lab.ald_recipes
.\.venv\Scripts\python.exe -m unittest native_lab.tests.test_ald_recipes -v
```

이 명령은 입력 JSON/CSV만 생성·검증하며 10개 물리 시뮬레이션을 실행하지 않는다.
모델 범위와 공정 간 형상 전달은 [연속공정 설명서](NATIVE_SEQUENCE_KR.md)에 정리했다.
